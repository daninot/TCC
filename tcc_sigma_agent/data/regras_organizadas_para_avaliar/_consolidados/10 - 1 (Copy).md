# Arquivo: D.yml
title: Web - SQLmap SQL Injection Scanner Activity Detected
id: a7c4e1b3-8f52-4d89-b016-3e9c74a27f58
status: test
description: |
    Detects automated SQL injection scanning by sqlmap, the most widely used
    open-source SQLi exploitation tool (37k+ GitHub stars). Three-tier detection:

    1. Tool signature (high confidence): Default sqlmap User-Agent
       "sqlmap/X.X.X#stable (https://sqlmap.org)" as defined in settings.py.
       Sent unless attacker explicitly uses --random-agent or --user-agent.

    2. Time-based payloads (medium): SLEEP(5), (SELECT(SLEEP()), WAITFOR DELAY,
       and pg_sleep() injected in URL parameters. sqlmap uses these for
       time-based blind SQLi detection starting at --level 1 (default).

    3. Error-based payloads (medium-high): CONCAT(0x71...), EXTRACTVALUE(),
       and UPDATEXML(). The 0x71 hex constant (ASCII 'q') is sqlmap's hardcoded
       output delimiter for data extraction — a near-unique tool fingerprint.

    Complement with the database error disclosure rule for full coverage.
    Real-world usage: 2015 TalkTalk breach, 2016 Illinois Board of Elections.
references:
    - https://github.com/sqlmapproject/sqlmap
    - https://github.com/sqlmapproject/sqlmap/wiki/FAQ
    - https://github.com/sqlmapproject/sqlmap/wiki/Usage
    - https://attack.mitre.org/techniques/T1190/
author: Security Team
date: 2026-05-25
tags:
    - attack.initial_access
    - attack.t1190   # Exploit Public-Facing Application
    - attack.discovery
    - attack.t1082   # System Information Discovery (DBMS fingerprinting)
logsource:
    category: webserver
detection:
    selection_tool_signature:
        # Default UA: "sqlmap/X.X.X#stable (https://sqlmap.org)"
        # Source: settings.py → DEFAULT_USER_AGENT = "%s (%s)" % (VERSION_STRING, SITE)
        c-useragent|contains:
            - 'sqlmap/'        # tool name + version separator
            - 'sqlmap.org'     # SITE constant always present in default UA
    selection_time_based:
        # Time-based blind SQLi payloads — sqlmap default since --level 1
        cs-uri-query|contains:
            - 'SLEEP(5)'               # MySQL/MariaDB time delay
            - '(SELECT(SLEEP('          # sqlmap nested SLEEP structure
            - "WAITFOR DELAY '0:0:"     # SQL Server time delay (sqlmap exact format)
            - 'pg_sleep('               # PostgreSQL time delay
            - ';SELECT PG_SLEEP('       # PostgreSQL stacked query variant
    selection_error_based:
        # Error-based extraction — sqlmap-specific hex delimiter and functions
        cs-uri-query|contains:
            - 'CONCAT(0x71'            # 0x71 = 'q' — sqlmap's hardcoded output delimiter
            - 'EXTRACTVALUE(1,'        # MySQL error-based extraction (sqlmap primary method)
            - 'UPDATEXML(1,'           # MySQL error-based extraction (sqlmap secondary method)
            - 'AND EXTRACTVALUE('      # MySQL boolean + error-based combined
    filter_authorized_scanners:
        # Suppress known authorized security testing sources.
        # Replace placeholder with your pentest team's CIDR ranges:
        # c-ip|cidr:
        #     - '10.10.100.0/24'   # pentest VLAN
        #     - '192.168.50.0/24'  # security team workstations
        c-ip: null   # placeholder — replace with authorized scanner CIDRs
    condition: (1 of selection_*) and not filter_authorized_scanners
fields:
    - c-ip
    - c-useragent
    - cs-uri-stem
    - cs-uri-query
    - sc-status
    - cs-method
falsepositives:
    - Authorized penetration testing — populate filter_authorized_scanners
    - Bug bounty hunters operating within defined scope and authorization
    - Security researchers running sqlmap against their own infrastructure
    - SLEEP() in legitimate app queries (only if cs-uri-query logging captures these)
level: high
---
