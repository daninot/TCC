title: Suspicious Mailbox Export Request
id: 7a2e1c4d-5b6f-4a8b-9c0d-1e2f3a4b5c6d
status: experimental
description: Detects usage of the PowerShell New-MailboxExportRequest cmdlet to export a mailbox to an atypical directory or with an aspx file suffix, indicating potential data exfiltration or webshell staging on an Exchange Server.
references:
  - https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/
  - https://blog.orange.tw/2021/08/proxylogon-a-new-attack-surface-on-ms-exchange-part-1.html
author: Senior Threat Detection Engineer
date: 2026-05-29
tags:
  - attack.exfiltration
  - attack.t1048
  - attack.persistence
  - attack.t1505.003
logsource:
  product: windows
  service: msexchange-management
detection:
  selection:
    - 'New-MailboxExportRequest'
    - ' -Mailbox '
    - '-FilePath "\\\\localhost\\C$'
    - '-FilePath "\\\\127.0.0.1\\C$'
    - '.aspx'
  condition: selection
falsepositives:
  - Legitimate administrative exports performed for backup, migration, or compliance purposes.
level: critical

# Arquivo: B.yml
title: Exchange - Suspicious PowerShell Cmdlet Abuse via Cmdlet History Log
id: c3e8b9a5-4d71-4f26-a892-7b5e3c9d1047
status: test
description: |
    Detects three critical Exchange abuse patterns via the Exchange PowerShell
    Cmdlet History logs (C:\Program Files\Microsoft\Exchange Server\V15\
    Logging\CmdletInfra\LocalPowerShell\Cmdlet\):

    1. Mailbox Export (New-MailboxExportRequest) to suspicious local paths —
       bulk PST export of e-mail data by a threat actor with Exchange admin
       privileges, documented as a real example in on-premises Exchange IR hunting.

    2. SMTP Forwarding Rule creation (Set-Mailbox ForwardingSmtpAddress /
       New-InboxRule ForwardTo / RedirectTo) to external domains — silent
       persistent data exfiltration that survives the attacker's ejection.

    3. Sensitive Role Assignment (New-ManagementRoleAssignment) granting
       a user Discovery Management, Organization Management, or Recipient
       Management — Exchange-level privilege escalation and persistent backdoor.

    Critical IR note: these cmdlet history files survive MSExchangeManagement
    Windows Event Log clearing, making them the primary fallback artifact
    when an attacker has wiped Exchange-related event logs.

    Log path: C:\Program Files\Microsoft\Exchange Server\V15\Logging\
              CmdletInfra\LocalPowerShell\Cmdlet\
    Filename: powershell.exe_<PID>_Cmdlet_<timestamp>
references:
    - https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/
    - https://attack.mitre.org/techniques/T1114/002/
    - https://attack.mitre.org/techniques/T1114/003/
    - https://attack.mitre.org/techniques/T1098/002/
author: Security Team
date: 2026-05-25
tags:
    - attack.collection
    - attack.t1114.002   # Email Collection: Remote Email Collection (mailbox export)
    - attack.t1114.003   # Email Collection: Email Forwarding Rule (SMTP forward)
    - attack.persistence
    - attack.t1098.002   # Account Manipulation: Exchange Email Delegate Permissions
logsource:
    product: exchange
    service: powershell_cmdlet
    definition: |
        Ingest from: C:\Program Files\Microsoft\Exchange Server\V15\Logging\
        CmdletInfra\LocalPowerShell\Cmdlet\*.log
        Fields header: DateTime,StartTime,...,AuthenticatedUser,...,IsAdmin,
        ClientApplication,Cmdlet,Parameters,...,ExecutionResult,ErrorType
detection:
    selection_mailbox_export:
        # Bulk PST export — a real-world example in the article (C:\Temp destination)
        Cmdlet: 'New-MailboxExportRequest'
        Parameters|contains:
            - '\Temp'             # attacker staging area (article example)
            - '\Public'           # world-readable share staging
            - 'C:\Windows\Temp'   # system temp as LOLbin staging path
    selection_smtp_forward:
        # Silent SMTP forwarding to external domain — article example: leon@external.tld
        Cmdlet|in:
            - 'Set-Mailbox'
            - 'New-InboxRule'
            - 'Set-InboxRule'
        Parameters|contains:
            - 'ForwardingSmtpAddress'
            - 'ForwardTo'
            - 'RedirectTo'
    selection_role_assignment:
        # Sensitive Exchange role grant — article example: Recipient Management
        Cmdlet: 'New-ManagementRoleAssignment'
        Parameters|contains:
            - 'Discovery Management'    # grants mailbox search/hold capabilities
            - 'Organization Management'  # full Exchange admin — highest privilege
            - 'Recipient Management'    # create/modify/delete all mailboxes
    filter_known_admins:
        # Suppress approved Exchange admin accounts during maintenance windows.
        # Replace placeholder with actual Exchange admin service accounts:
        # AuthenticatedUser:
        #     - 'DOMAIN\svc-exchange'
        #     - 'DOMAIN\ExchangeAdmin'
        AuthenticatedUser: null   # placeholder — populate with known admin accounts
    condition: (1 of selection_*) and not filter_known_admins
fields:
    - DateTime
    - AuthenticatedUser
    - IsAdmin
    - Cmdlet
    - Parameters
    - ExecutionResult
    - ClientApplication
falsepositives:
    - Legitimate IT migrations exporting mailboxes to PST during approved windows
    - Business-authorized email forwarding for executive/VIP accounts
    - Authorized Exchange role delegation during onboarding/offboarding processes
    - Exchange setup automation scripts running New-ManagementRoleAssignment
level: high

# Arquivo: C.yml
title: Exchange Inbox Rule Creation via PowerShell or EWS
id: 9d3f2b6e-8f4a-4c2b-9a1e-2b7c6f5a1e2d
status: experimental
description: Detects creation or modification of mailbox inbox rules (used for persistence or stealthy data exfiltration) via PowerShell or EWS calls on on-premises Exchange servers. Based on hunting guidance for on-prem Exchange logs.
author: Daniela
date: 2026-05-30
references:
  - https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/
logsource:
  product: windows
  service: powershell
  category: process_creation
detection:
  selection_powershell_inboxrule:
    CommandLine|contains:
      - "New-InboxRule"
      - "Set-InboxRule"
      - "Remove-InboxRule"
      - "New-InboxRule -Mailbox"
      - "Set-InboxRule -Mailbox"
  selection_ews_requests:
    EventID:
      - 4624
    LogName: "Application"
    Source|contains:
      - "MSExchange Web Services"
    Message|contains:
      - "CreateInboxRule"
      - "UpdateInboxRule"
  condition: selection_powershell_inboxrule or selection_ews_requests
fields:
  - timestamp
  - User
  - ComputerName
  - CommandLine
  - ProcessId
  - ParentImage
  - EventID
  - Source
  - Message
falsepositives:
  - Legitimate administrative automation or scripted mailbox management
  - Bulk mailbox maintenance performed by Exchange administrators or management tools
level: high
tags:
  - attack.persistence
  - attack.exfiltration
  - attack.t1114

# Arquivo: E.yml
title: Suspicious PowerShell Mailbox Export via New-MailboxExportRequest
id: 4a241dea-235b-4a7e-8d76-50d817b146c4
status: test
description: Detects the execution of the PowerShell 'New-MailboxExportRequest' cmdlet used to extract mailbox contents to a local or remote network share. This technique is commonly abused by adversaries during the post-compromise or exfiltration phase of an on-premises Microsoft Exchange server breach (e.g., following ProxyShell or ProxyNotShell exploitation).
references:
    - https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/
author: Security Operations Center
date: 2022/10/26
modified: 2026/05/30
tags:
    - attack.collection
    - attack.exfiltration
    - attack.t1114.002 # Email Collection: Remote Email Collection
logsource:
    product: windows
    category: process_creation
detection:
    selection:
        CommandLine|contains: 'New-MailboxExportRequest'
    selection_parameters:
        CommandLine|contains:
            - '-Mailbox'
            - '-FilePath'
    condition: selection and all of selection_parameters
falsepositives:
    - Authorized Exchange administrators performing routine email archives, backup procedures, or employee offboarding tasks.
level: high
