# Arquivo: D.yml
title: Remote Printing RPC Interface Abuse via MS-RPRN or MS-PAR
id: 9f1a3e7b-2d4c-4b8f-a6e5-7c3d1f9b2a84
status: experimental
description: >
  Detects remote RPC calls targeting the MS-RPRN (Print System Remote Protocol)
  or MS-PAR (Print System Asynchronous Remote Protocol) interfaces, as recorded
  by the Zero Networks RPC Firewall agent. These printing-protocol interfaces
  underpin the PrintNightmare class of attacks (CVE-2021-34527), which abuse
  the Windows Print Spooler RpcAddPrinterDriver / RpcAsyncAddPrinterDriver RPC
  methods to achieve remote code execution and lateral movement across hosts
  where the Spooler service is reachable over the network. All four UUIDs that
  represent the MS-RPRN and MS-PAR interface variants abused in the wild are
  included. Detection requires the RPC Firewall agent to be installed and
  configured to audit all processes with the relevant interface UUIDs;
  recommended configuration snippet:
  audit:true action:block uuid:12345678-1234-abcd-ef00-0123456789ab or
  76f03f96-cdfd-44fc-a22c-64950a001209 or ae33069b-a2a8-46ee-a235-ddfd339be281
  or 0b6edbfa-4a24-4fc6-8a23-942b1eca65d1
references:
  - https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34527
  - https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-rprn/d42db7d5-f141-4466-8f47-0a4be14e2fc1
  - https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-pan/e44d984c-07d3-414c-8ffc-f8c8ad8512a8
  - https://github.com/jsecurity101/MSRPC-to-ATTACK/blob/ddd4608fe8684fcf2fcf9b48c5f0b3c28097f8a3/documents/MS-RPRN-PAR.md
  - https://github.com/zeronetworks/rpcfirewall
  - https://zeronetworks.com/blog/stopping-lateral-movement-via-the-rpc-firewall/
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.lateral_movement
  - attack.t1210
logsource:
  product: rpc_firewall
  category: application
  definition: >
    Requirements: install and apply the RPC Firewall agent to all processes
    with audit:true targeting uuid:12345678-1234-abcd-ef00-0123456789ab,
    76f03f96-cdfd-44fc-a22c-64950a001209, ae33069b-a2a8-46ee-a235-ddfd339be281,
    and 0b6edbfa-4a24-4fc6-8a23-942b1eca65d1 to capture MS-RPRN and MS-PAR
    interface invocations.
detection:
  selection:
    EventLog: RPCFW
    EventID: 3
    InterfaceUuid:
      - 12345678-1234-abcd-ef00-0123456789ab
      - 76f03f96-cdfd-44fc-a22c-64950a001209
      - ae33069b-a2a8-46ee-a235-ddfd339be281
      - 0b6edbfa-4a24-4fc6-8a23-942b1eca65d1
  condition: selection
falsepositives:
  - Legitimate printing activity from workstations or print servers that invoke
    the MS-RPRN or MS-PAR interfaces as part of normal print job submission,
    driver enumeration, or printer status notifications; environments with
    active print infrastructure will see a high baseline volume of matching
    events and should enrich with source-host context before alerting.
level: high
