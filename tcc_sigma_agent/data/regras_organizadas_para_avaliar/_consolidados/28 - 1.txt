# Arquivo: A.yml
title: Execution of Potentially Malicious Tooling Identified by JP-CERT Tool Analysis Patterns
id: 3b9f2d1e-2026-jpcert-tool-analysis
status: experimental
description: Detects execution patterns consistent with suspicious or malicious tooling as described in JP-CERT research and the Tool Analysis Result Sheet (unexpected binaries executed from user/temp paths, unsigned or packed installers, common offensive tool names or reconnaissance flags, and unusual parent processes). Useful for catching commodity offensive tools, one-off tool drops, and attacker toolchains that match analysis-sheet indicators.
author: Detection Engineer
date: 2026-06-05
references:
  - https://www.jpcert.or.jp/english/pub/sr/ir_research.html
  - https://jpcertcc.github.io/ToolAnalysisResultSheet
logsource:
  product: windows
  service: sysmon
  category: process_creation
detection:
  selection_temp_execution:
    EventID: 1
    Image|contains:
      - "\\AppData\\Local\\Temp\\"
      - "\\AppData\\Roaming\\"
      - "\\Temp\\"
      - "\\Downloads\\"
      - "\\Users\\"
  selection_suspicious_names:
    EventID: 1
    Image|re:
      - '(?i)\\(nmap|masscan|mimikatz|procdump|cobaltstrike|c2|beacon|sharp|socks|impacket|psexec|bloodhound|responder|crackmapexec|evil-winrm|rclone|rclone.exe)$'
  selection_command_recon:
    EventID: 1
    CommandLine|re:
      - '(?i)\b(nmap|masscan|netstat|ipconfig|ifconfig|arp|route|whoami|net user|net localgroup|Get-LocalGroup|Get-LocalUser|Invoke-Command|Invoke-Expression|IEX)\b'
  selection_parent_unusual:
    EventID: 1
    ParentImage|re:
      - '(?i)\\(winword|excel|powerpnt|outlook|chrome|firefox|edge|svchost|explorer)\.exe$'
  selection_unsigned_indicator:
    EventID: 1
    Image|endswith:
      - ".exe"
    Signed: "false"
  condition: (selection_temp_execution and (selection_suspicious_names or selection_command_recon or selection_unsigned_indicator)) or (selection_suspicious_names and selection_parent_unusual)
fields:
  - timestamp
  - EventID
  - ComputerName
  - SubjectUserName
  - Image
  - ParentImage
  - CommandLine
  - ProcessId
  - Signed
falsepositives:
  - Legitimate developer, pentest, or red-team tooling used by authorized staff
  - Enterprise installers or updater tools that temporarily run from Downloads or Temp (whitelist known vendor installers)
  - Administrative troubleshooting tools executed from user contexts
level: high
tags:
  - attack.execution
  - attack.discovery
  - detection.endpoint
  - jpcert
  - tool-analysis
notes: |
  - Tune by whitelisting known automation, developer, and security testing accounts and hosts.
  - Enrich alerts with file hash, digital signature details, and telemetry from EDR (file creation, parent/child trees, network connections).
  - Investigate by collecting the binary, computing hashes, checking reputation, reviewing parent/child processes, and searching the environment for other instances or related IOCs.

# Arquivo: B.yml
title: Remote Event Log Deletion via Wevtutil RPC Connection
id: 7f3a9d24-c18e-4b05-af62-3e72d0b84f91
status: experimental
description: |
    Detects wevtutil.exe establishing an outbound TCP connection to port 135 (RPC
    Endpoint Mapper), which occurs exclusively when wevtutil is used with the /r: flag
    to clear or query event logs on a remote host.

    Legitimate administrators nearly always clear logs locally. During lateral movement
    campaigns, attackers use "wevtutil cl [LogName] /r:[TargetHost]" from a staging host
    to wipe forensic evidence across multiple machines simultaneously without needing to
    log into each target interactively. This remote invocation causes wevtutil.exe to
    contact the target's RPC Endpoint Mapper (TCP/135) to negotiate a dynamic port for
    the Windows Event Log (wevtsvc) RPC interface before issuing the clear command.

    This specific behaviour — wevtutil.exe owning a network connection to port 135 — is
    documented by JPCERT/CC in their Tool Analysis Result Sheet as Sysmon Event ID 3
    generated on the source host side. On the destination host, the successful clear
    produces Security Event ID 104 (System log) or Security Event ID 1102 (Security log),
    and a DATA_OVERWRITE+DATA_TRUNCATION entry in the USN journal for the target .evtx
    file.

references:
    - https://www.jpcert.or.jp/english/pub/sr/ir_research.html
    - https://jpcertcc.github.io/ToolAnalysisResultSheet/details/wevtutil.htm
    - https://jpcertcc.github.io/ToolAnalysisResultSheet
author: Generated from JPCERT/CC Tool Analysis Result Sheet (Detecting Lateral Movement through Tracking Event Logs)
date: 2024-01-01
tags:
    - attack.defense_evasion
    - attack.t1070.001   # Indicator Removal: Clear Windows Event Logs
    - attack.lateral_movement
    - attack.t1021.002   # Remote Services: SMB/Windows Admin Shares (RPC-initiated)
    - tlp:white
logsource:
    product: windows
    category: network_connection
    # Requires Sysmon with NetworkConnect events (Event ID 3) enabled.
    # The rule fires on the SOURCE host (the host running wevtutil with /r:).
detection:
    selection:
        EventID: 3
        Image|endswith: '\wevtutil.exe'
        DestinationPort: 135
        Initiated: 'true'   # Sysmon field: outbound connection initiated by this process

    filter_local_loopback:
        # Local loopback means wevtutil is operating on the local host — not a threat.
        DestinationIp|startswith:
            - '127.'
            - '::1'

    condition: selection and not filter_local_loopback

falsepositives:
    - A sysadmin legitimately using "wevtutil cl /r:<hostname>" to clear logs on a
      managed remote host as part of a documented maintenance procedure. Validate against
      change management records and correlate with destination Event ID 104/1102.
    - Monitoring or SIEM agent wrappers that invoke wevtutil remotely for log collection
      (rare; most agents use the Windows Event Collector / WEF subscription mechanism
      instead, which does not invoke wevtutil.exe directly).
level: high

# Arquivo: C.yml
title: Credential Dumping via Native Windows Utilities - JPCERT Matrix
id: 93b3f2a1-fa1d-44a6-98dc-ee9a81da70df
status: experimental
description: Detects the use of built-in Windows utilities (such as esentutl.exe or ntdsutil.exe) to copy, dump, or create snapshots of the Active Directory database (ntds.dit). This behavioral pattern aligns with forensic evidence analyzed in the JPCERT/CC Tool Analysis Result Sheet, where adversaries leverage living-off-the-land binaries to extract the database for offline credential harvesting.
references:
    - https://www.jpcert.or.jp/english/pub/sr/ir_research.html
    - https://jpcertcc.github.io/ToolAnalysisResultSheet/
author: Security Operations Center
date: 2026/06/05
tags:
    - attack.credential_access
    - attack.t1003.003 # OS Credential Dumping: NTDS
logsource:
    product: windows
    category: process_creation
detection:
    selection_esentutl:
        Image|endswith: '\esentutl.exe'
        CommandLine|contains|all:
            - '/y'
            - 'ntds.dit'
    selection_ntdsutil_interactive:
        Image|endswith: '\ntdsutil.exe'
        CommandLine|contains|all:
            - 'ac'
            - 'i'
            - 'ntds'
    selection_ntdsutil_ifm:
        Image|endswith: '\ntdsutil.exe'
        CommandLine|contains: 'ifm'
    condition: 1 of selection_*
falsepositives:
    - Authorized domain controller backup operations, disaster recovery simulation exercises, or routine Active Directory database integrity validation routines orchestrated by network administrators.
level: critical
