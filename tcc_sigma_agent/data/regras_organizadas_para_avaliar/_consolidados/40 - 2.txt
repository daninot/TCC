description: Detects creation of a Python path configuration file (.pth) in macOS Python site-packages folders, which executes code at Python startup and has been exploited in CVE-2024-3400 (Palo Alto GlobalProtect).
references:

author: Senior Threat Detection Engineer
date: 2026-06-06

    product: macos
    category: file_event

        TargetFilename|endswith: '.pth'
    condition: selection_path and selection_ext

    - Legitimate Python package installations that create .pth files
level: high

# Arquivo: B.yml
title: Creation of Python .pth File in macOS site-packages Directory
id: c3a9f2b4-7d6e-4f8a-9b1c-2e3f4a5b6c7d
status: experimental
description: Detects creation of Python path configuration files (.pth) within macOS Python site-packages directories for Python 3.5 and above. .pth files are executed at Python startup and can be abused for persistence and arbitrary code execution. Requires file creation monitoring that captures the full target file path.
author: Senior Threat Detection Engineer
date: 2026/06/11
references:
  - [https://www.volexity.com/blog/2024/04/12/zero-day-exploitation-of-unauthenticated-remote-code-execution-vulnerability-in-globalprotect-cve-2024-3400/](https://www.volexity.com/blog/2024/04/12/zero-day-exploitation-of-unauthenticated-remote-code-execution-vulnerability-in-globalprotect-cve-2024-3400/)
  - [https://docs.python.org/3/library/site.html](https://docs.python.org/3/library/site.html)
tags:
  - attack.persistence
  - attack.execution
  - supply_chain
  - macos
logsource:
  product: macos
  category: file_event
  description: File creation events from macOS endpoint telemetry (e.g., auditd, osquery, or EDR file monitoring) that include the full TargetFilePath. Ensure file create events are collected.
detection:
  selection_path_regex:
    TargetFilePath|re: '(?i).*(?:/Library/Frameworks/Python.framework/Versions/\\d+\\.\\d+/lib/python\\d\\.\\d+/site-packages/|/usr/local/lib/python3\\.(?:[5-9]|[1-9]\\d)/site-packages/|/usr/lib/python3\\.(?:[5-9]|[1-9]\\d)/site-packages/|/Library/Python/3\\.(?:[5-9]|[1-9]\\d)/site-packages/|/Users/[^/]+/Library/Python/3\\.(?:[5-9]|[1-9]\\d)/lib/python/site-packages/).*'
  selection_ext:
    TargetFilePath|endswith:
      - '.pth'
      - '.PTH'
  condition: all of selection_path_regex selection_ext
falsepositives:
  - Legitimate package installers or developers adding .pth files during package installation or virtual environment setup.
  - Automated build or CI processes that write .pth files into site-packages as part of packaging or testing.
level: high

This technique was observed in exploitation of CVE-2024-3400 affecting Palo Alto GlobalProtect.

    - https://docs.python.org/3/library/site.html
author: Senior Threat Detection Engineer
date: 2024-01-01
tags:
    - attack.persistence
    - attack.execution
    - attack.t1546
    - attack.t1059.006
    - cve.2024.3400
logsource:
    product: macos
    category: file_event
detection:
    selection_path:
        TargetFilename|re: '(?i)/[Pp]ython3\.[0-9]{1,2}/site-packages/'
    selection_extension:
        TargetFilename|endswith: '.pth'
    condition: all of selection_*
falsepositives:
    - Legitimate Python package installations via pip or other package managers creating .pth files in site-packages
    - Developer tooling or virtual environment setup scripts generating path configuration files
level: high

title: Python Path Configuration File Creation - MacOS
id: 4f394635-13ef-4599-b677-3353e0f84f55

status: test
description: |
    Detects creation of a Python path configuration file (.pth) in Python library folders, which can be maliciously abused for code execution and persistence.
    Modules referenced by these files are run at every Python startup (v3.5+), regardless of whether the module is imported by the calling script.
    Default paths are '\lib\site-packages\*.pth' (Windows) and '/lib/pythonX.Y/site-packages/*.pth' (Unix and macOS).
references:
    - https://www.volexity.com/blog/2024/04/12/zero-day-exploitation-of-unauthenticated-remote-code-execution-vulnerability-in-globalprotect-cve-2024-3400/
    - https://www.virustotal.com/gui/file/3de2a4392b8715bad070b2ae12243f166ead37830f7c6d24e778985927f9caac
    - https://docs.python.org/3/library/site.html
author: Andreas Braathen (mnemonic.io)
date: 2024-04-25
tags:
    - attack.execution
    - attack.t1059.006
    - detection.threat-hunting
logsource:
    product: macos
    category: file_event
detection:
    selection:
        TargetFilename|re: '(?i)/lib/python3\.([5-9]|[0-9]{2})/site-packages/' # Unix and macOS
        TargetFilename|endswith: '.pth'
    condition: selection
falsepositives:
    - Although .pth files are discouraged due to potential security implications, these are legitimate files by specification.
level: medium
