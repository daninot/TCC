# Arquivo: B.yml
title: Huawei BGP Authentication Failure Detected
id: f6a3d2b1-8c5e-4f7a-b4d3-9e1c6f2a8b74
status: experimental
description: >
  Detects BGP authentication failures logged by a Huawei network device.
  The rule matches on the co-occurrence of the BGP protocol port marker (179)
  and the authentication failure error string emitted by Huawei VRP in its BGP
  subsystem syslog messages. Repeated failures are a strong indicator of an
  offline or online brute-force attempt against the MD5 shared secret protecting
  a BGP peering session (RFC 2385). A successful compromise of BGP authentication
  can enable an adversary to hijack routing, redirect or blackhole traffic,
  insert malicious prefixes, or establish persistent adversary-in-the-middle
  positioning on the routing fabric. Log ingestion requires Huawei BGP syslog
  output to be enabled on the target device and forwarded to a centralised
  log collector or SIEM. Detection relies on keyword matching against raw,
  unstructured syslog text; no structured field names are available in this
  log format.
references:
  - https://www.blackhat.com/presentations/bh-usa-03/bh-us-03-convery-franz-v3.pdf
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.credential_access
  - attack.initial_access
  - attack.persistence
  - attack.t1110.001
logsource:
  product: huawei
  service: bgp
detection:
  keywords|all:
    - 'BGP'
    - '179'
    - 'authentication'
    - 'fail'
  condition: keywords
falsepositives:
  - Misconfigured BGP peers where the MD5 authentication key on one side
    of a peering session does not match the other, causing a stream of
    legitimate authentication failure messages with no malicious intent.
  - Planned network changes or migrations in which a peer's authentication
    key is updated on one device before the other, producing a transient
    burst of failures until both sides are synchronised.
  - Network monitoring or health-check tooling that initiates BGP connection
    probes without supplying the correct authentication credentials.
level: medium
