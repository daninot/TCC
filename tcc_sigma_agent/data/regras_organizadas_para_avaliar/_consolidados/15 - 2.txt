# Arquivo: A.yml
title: Registry Run Key Modification by WINEKEY / Team9 Backdoor
id: 5b3c9d2e-1f4a-4e6b-9c7d-2a1f0e8b6c3d
status: experimental
description: Detects registry write events that create or modify Run key entries consistent with persistence by the WINEKEY or Team9 backdoor. Matches writes to standard Run key paths and looks for value names or data that reference known backdoor identifiers or that attempt to masquerade as backup manager applications.
author: Senior Threat Detection Engineer
date: 2026/06/02
references:
  - [https://www.fireeye.com/blog/threat-research/2020/10/kegtap-and-singlemalt-with-a-ransomware-chaser.html](https://www.fireeye.com/blog/threat-research/2020/10/kegtap-and-singlemalt-with-a-ransomware-chaser.html)
tags:
  - attack.persistence
  - attack.t1547.001
  - malware.winekey
  - malware.team9
logsource:
  product: windows
  category: registry_event
  description: Windows registry write events (create/modify) that include RegistryKey, RegistryValueName, and RegistryValueData.
detection:
  selection_runkey:
    RegistryKey|endswith:
      - '\\Software\\Microsoft\\Windows\\CurrentVersion\\Run'
      - '\\Software\\Wow6432Node\\Microsoft\\Windows\\CurrentVersion\\Run'
  selection_malicious_name:
    RegistryValueName|contains:
      - 'WINEKEY'
      - 'WineKey'
      - 'Team9'
      - 'team9'
      - 'Backup'
      - 'backup'
      - 'BackupManager'
      - 'BackupMgr'
  selection_malicious_data:
    RegistryValueData|contains:
      - 'winekey'
      - 'winekey.exe'
      - 'team9'
      - 'team9.exe'
      - '\\AppData\\'
      - '\\Temp\\'
      - '.exe'
  condition: selection_runkey and (selection_malicious_name or selection_malicious_data)
falsepositives:
  - Legitimate backup or management software that creates Run entries (e.g., vendor-signed backup agents).
  - Endpoint management or deployment tools that register autostart entries.
level: high

# Arquivo: B.yml
title: WINEKEY or Team9 Backdoor Persistence via Run Key Backup Mgr
id: e9f2c3a7-1b4d-4e8f-b5c2-7d3a1e6f9b24
status: stable
description: >
  Detects the creation or modification of a Windows registry Run key entry
  named Backup Mgr under the CurrentVersion\Run hive, a persistence mechanism
  documented as characteristic of the WINEKEY backdoor, also tracked as
  CORKBOT, BazarBackdoor, and Team9. WINEKEY is a post-compromise backdoor
  deployed as part of a ransomware-enabling kill chain alongside the
  KEGTAP/BazarLoader dropper. Mandiant observed this family throughout 2020
  in campaigns that culminated in the deployment of Ryuk and Conti ransomware,
  sometimes within 24 hours of initial access. The Run key value name Backup
  Mgr is chosen to masquerade as a legitimate backup management application,
  blending into the noise of enterprise startup entries. The endswith modifier
  on TargetObject covers both HKCU and HKLM hive paths as well as per-user
  paths logged under HKU\<SID>, providing full coverage regardless of which
  hive the malware targets on a given host.
references:
  - https://www.fireeye.com/blog/threat-research/2020/10/kegtap-and-singlemalt-with-a-ransomware-chaser.html
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.persistence
  - attack.defense_evasion
  - attack.t1547.001
  - attack.t1112
logsource:
  category: registry_event
  product: windows
detection:
  selection:
    TargetObject|endswith: '\Software\Microsoft\Windows\CurrentVersion\Run\Backup Mgr'
  condition: selection
falsepositives:
  - A legitimate third-party backup management application that registers
    itself under the exact Run key name Backup Mgr during installation.
    This is considered highly unlikely given the specificity of the value
    name; any match should be investigated and the backing executable
    verified against a known-good application catalogue before dismissal.
level: high
