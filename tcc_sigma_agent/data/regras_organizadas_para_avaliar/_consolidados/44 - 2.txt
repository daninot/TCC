# Arquivo: A.yml
title: Non-DLL File Renamed to DLL Extension
id: 4b7e2a9c-1f3d-4e8b-a6c5-8d2f1b9e3a7c
status: experimental
description: |
    Detects file rename operations where a non-DLL file is renamed to a .dll
    extension, a masquerading technique used by malware to evade extension-based
    detections after dropping a payload with an innocuous initial extension.
    Requires Microsoft-Windows-Kernel-File provider with at least the
    KERNEL_FILE_KEYWORD_RENAME_SETLINK_PATH keyword enabled.
references:
    - https://twitter.com/ffforward/status/1481672378639912960
    - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1036/T1036.md#atomic-test-1---system-file-copied-to-unusual-location
author: Senior Threat Detection Engineer
date: 2024-03-01
tags:
    - attack.defense-evasion
    - attack.t1036.008
logsource:
    category: file_rename
    product: windows
detection:
    selection:
        TargetFilename|endswith: '.dll'
    filter_main_dll_source:
        OldFilename|endswith: '.dll'
    filter_main_tmp_source:
        OldFilename|endswith: '.tmp'
    filter_main_empty_source:
        OldFilename:
            - ''
            - null
    filter_main_tiworker:
        Image|endswith: '\TiWorker.exe'
        Image|contains: '\Windows\WinSxS\'
    filter_main_windows_update:
        - Image|endswith: '\wuauclt.exe'
        - TargetFilename|contains: ':\$WINDOWS.~BT\Sources\'
    filter_main_program_files:
        TargetFilename|contains:
            - ':\Program Files\'
            - ':\Program Files (x86)\'
    filter_optional_squirrel:
        Image|contains: '\Squirrel.exe'
        OldFilename|contains: '.tmp'
    condition: selection and not 1 of filter_main_* and not 1 of filter_optional_*
falsepositives:
    - Legitimate software installers that stage DLL files under temporary
      non-DLL extensions before renaming
    - Custom enterprise deployment tooling performing in-place DLL updates
level: medium

title: File Renamed To .dll From Non DLL Source
id: 2e9f4b7c-1a6d-4c3f-9b2e-0f1a2c3d4e5f
status: experimental
description: Detects file rename operations where a file is renamed to a .dll extension but the source file was not a DLL. This masquerading technique is used by malware to evade extension-based detections after dropping a payload with an innocuous extension. Requires Kernel File provider with rename/setlink path keyword enabled to capture rename events.
author: Senior Threat Detection Engineer
date: 2026/06/12
references:
  - [https://twitter.com/ffforward/status/1481672378639912960](https://twitter.com/ffforward/status/1481672378639912960)
  - [https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1036/T1036.md#atomic-test-1---system-file-copied-to-unusual-location](https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1036/T1036.md#atomic-test-1---system-file-copied-to-unusual-location)
tags:
  - attack.defense_evasion
  - malware
  - windows
  - file_rename
logsource:
  product: windows
  category: file_rename
  description: Microsoft-Windows-Kernel-File provider must be enabled with the KERNEL_FILE_KEYWORD_RENAME_SETLINK_PATH keyword to capture rename/setlink path events. Ensure rename events include SourceFilePath, TargetFilePath, and Image (process) fields.
detection:
  selection:
    TargetFilePath|endswith:
      - '.dll'
  filter_main_1:
    SourceFilePath|endswith:
      - '.dll'
  filter_main_2:
    SourceFilePath|endswith:
      - '.tmp'
      - '.TMP'
  filter_main_3:
    SourceFilePath|in:
      - ''
      - 'NULL'
      - 'null'
  filter_main_4:
    Image|endswith:
      - '\\TiWorker.exe'
    Image|contains:
      - '\\Windows\\WinSxS\\'
  filter_main_5:
    Image|endswith:
      - '\\wuauclt.exe'
  filter_main_6:
    TargetFilePath|contains:
      - ':$WINDOWS.~BT\\Sources\\'
  filter_main_7:
    TargetFilePath|contains:
      - '\\Program Files\\'
      - '\\Program Files (x86)\\'
  filter_optional_1:
    SourceFilePath|contains:
      - 'SquirrelTemp'
      - '\\SquirrelTemp\\'
  condition: selection and not 1 of filter_main_1 filter_main_2 filter_main_3 filter_main_4 filter_main_5 filter_main_6 filter_main_7 and not 1 of filter_optional_1
falsepositives:
  - Legitimate installer or updater workflows that stage files in temporary locations and rename them to .dll as part of installation.
  - Windows servicing and update operations (TiWorker, Windows Update) and software deployment tools that rename files during patching.
  - Squirrel or other auto-updaters that use temporary rename patterns.
level: high
