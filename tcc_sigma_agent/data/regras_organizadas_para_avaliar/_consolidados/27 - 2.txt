# Arquivo: A.yml
title: Suspicious ActionController Exception Classes in Rails Application Logs
id: 4f2a9b6c-8d3e-4a1f-b7c2-5e6d9a0b1c2f
status: experimental
description: Detects Rails application log entries that include ActionController exception class names commonly raised by malformed requests, CSRF token failures, invalid HTTP methods, or missing parameters. These exceptions can indicate exploitation attempts such as CSRF token abuse, cross-origin request forgery, malformed requests, or automated probing.
author: Senior Threat Detection Engineer
date: 2026/06/06
references:
  - [http://edgeguides.rubyonrails.org/security.html](http://edgeguides.rubyonrails.org/security.html)
  - [http://guides.rubyonrails.org/action_controller_overview.html](http://guides.rubyonrails.org/action_controller_overview.html)
  - [https://stackoverflow.com/questions/25892194/does-rails-come-with-a-not-authorized-exception](https://stackoverflow.com/questions/25892194/does-rails-come-with-a-not-authorized-exception)
  - [https://github.com/rails/rails/blob/cd08e6bcc4cd8948fe01e0be1ea0c7ca60373a25/actionpack/lib/action_dispatch/middleware/exception_wrapper.rb](https://github.com/rails/rails/blob/cd08e6bcc4cd8948fe01e0be1ea0c7ca60373a25/actionpack/lib/action_dispatch/middleware/exception_wrapper.rb)
tags:
  - attack.exploitation
  - web
  - ruby_on_rails
logsource:
  product: ruby_on_rails
  category: application
  description: Unstructured Rails application logs containing exception class names and stack traces (e.g., production.log). Ensure application logging captures exception class names.
detection:
  selection_exception:
    Message|contains:
      - 'ActionController::InvalidAuthenticityToken'
      - 'ActionController::InvalidCrossOriginRequest'
      - 'ActionController::UnknownHttpMethod'
      - 'ActionController::ParameterMissing'
      - 'ActionController::BadRequest'
      - 'ActionController::RoutingError'
      - 'ActionController::MethodNotAllowed'
      - 'ActionController::UnknownFormat'
  condition: selection_exception
falsepositives:
  - Legitimate client errors from misconfigured clients, API consumers, or integration tests.
  - Automated health checks, vulnerability scanners, or load testing that send malformed requests.
level: medium
