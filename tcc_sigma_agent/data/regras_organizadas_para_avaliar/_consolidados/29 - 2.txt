  * '.ps1'

  * '.js'
  * '.jse'

* User-created shortcuts or scripts placed in the Startup folder intentionally

# Arquivo: E.yml
title: Creation of Potentially Malicious Files in Windows Startup Folder
id: 7f4b2c1d-9a6e-4d3f-b8c2-1e5f7a9b0c3d
status: experimental
description: Detects creation of script or executable files placed in Windows Startup folders which may be used for persistence. Flags files created under user or system Startup locations with extensions commonly abused for persistence and malware delivery.
author: Senior Threat Detection Engineer
date: 2026/06/06
references:
  - [https://github.com/last-byte/PersistenceSniper](https://github.com/last-byte/PersistenceSniper)
  - [https://www.microsoft.com/en-us/security/blog/2025/03/06/malvertising-campaign-leads-to-info-stealers-hosted-on-github/](https://www.microsoft.com/en-us/security/blog/2025/03/06/malvertising-campaign-leads-to-info-stealers-hosted-on-github/)
  - [https://github.com/redcanaryco/atomic-red-team/blob/5ede8f21e42ebe37e0a6eff757dba60bcfa85859/atomics/T1547.001/T1547.001.md](https://github.com/redcanaryco/atomic-red-team/blob/5ede8f21e42ebe37e0a6eff757dba60bcfa85859/atomics/T1547.001/T1547.001.md)
tags:
  - attack.persistence
  - attack.t1547.001
  - windows
  - persistence
logsource:
  product: windows
  category: file_event
  description: File creation events from auditd-like sources, Sysmon, or file integrity monitoring that include FilePath and Action fields. Ensure file create events are collected.
detection:
  selection_path:
    FilePath|contains:
      - '\\AppData\\Roaming\\Microsoft\\Windows\\Start Menu\\Programs\\Startup'
      - '\\ProgramData\\Microsoft\\Windows\\Start Menu\\Programs\\Startup'
      - '\\Start Menu\\Programs\\Startup'
  selection_ext:
    FilePath|endswith:
      - '.ps1'
      - '.psm1'
      - '.vbs'
      - '.js'
      - '.jse'
      - '.bat'
      - '.cmd'
      - '.hta'
      - '.lnk'
      - '.exe'
      - '.dll'
      - '.jar'
      - '.msc'
  condition: selection_path and selection_ext
falsepositives:
  - Legitimate installers, user scripts, or IT automation that place shortcuts or scripts in Startup for valid operational reasons.
  - Software deployment or user provisioning workflows that register startup tasks during onboarding.
level: high
