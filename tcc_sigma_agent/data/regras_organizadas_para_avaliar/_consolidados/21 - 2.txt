# Arquivo: A.yml
title: Kubernetes Audit Events Modifying or Deleting Secrets
id: b7e4c2d1-9a6f-4b3e-8c2d-1f5a6b7c8d9e
status: experimental
description: Detects Kubernetes API server audit events that create, update, patch, replace, or delete Secret resources. Modification or deletion of Secrets may indicate credential theft, tampering, or attempts to cover tracks by an attacker with sufficient RBAC permissions. Requires Kubernetes audit logging to be enabled and collected.
author: Senior Threat Detection Engineer
date: 2026/06/05
references:
  - [https://kubernetes.io/docs/reference/config-api/apiserver-audit.v1/](https://kubernetes.io/docs/reference/config-api/apiserver-audit.v1/)
  - [https://commandk.dev/blog/guide-to-audit-k8s-secrets-for-compliance/](https://commandk.dev/blog/guide-to-audit-k8s-secrets-for-compliance/)
tags:
  - attack.credential_access
  - attack.exfiltration
  - kubernetes
logsource:
  product: kubernetes
  service: audit
  category: audit
  description: Kubernetes API server audit logs must be enabled and forwarded to the SIEM. Audit policy should capture requestURI, verb, user, and objectRef fields.
detection:
  selection:
    verb|in:
      - 'create'
      - 'update'
      - 'patch'
      - 'replace'
      - 'delete'
      - 'deletecollection'
    objectRef.resource:
      - 'secrets'
  condition: selection
falsepositives:
  - Legitimate administrative or automation activity creating, rotating, or deleting secrets (CI/CD pipelines, operators, secret-rotation controllers).
  - Cluster lifecycle operations or namespace cleanup jobs that remove secrets as part of normal maintenance.
level: high

# Arquivo: D.yml
title: Antivirus Detection of Malicious DLL in Print Spooler Driver Directory
id: 9e3c7f2a-4b1d-4e8c-b7f3-2d5a1c8e4b37
status: stable
description: >
  Detects antivirus alerts for files created inside the Windows Print Spooler
  x64 driver directory that are characteristic of PrintNightmare
  (CVE-2021-34527 and CVE-2021-1675) exploitation. Both vulnerabilities allow
  an authenticated attacker to cause the Spooler service to load an arbitrary
  DLL from a path under the driver directory, resulting in code execution as
  SYSTEM. Proof-of-concept and weaponised exploit tools drop a malicious DLL
  into C:\Windows\System32\spool\drivers\x64\ before triggering a privileged
  print driver installation call. Antivirus or EDR telemetry capturing file
  creation events in this path is therefore a high-confidence indicator of
  exploitation in progress. The known Symantec pending-analysis signatures
  (Suspicious.Cloud.7.EP and Suspicious.Cloud.9.EP) are excluded to suppress
  noise from PSP heuristic telemetry that incorrectly flags legitimate driver
  files in the same directory, as reported by field responders shortly after
  initial PoC publication. All other antivirus signatures firing on this path
  remain alertable.
references:
  - https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-1675
  - https://msrc.microsoft.com/update-guide/vulnerability/CVE-2021-34527
  - https://twitter.com/mvelazco/status/1410291741241102338
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.privilege_escalation
  - attack.t1068
logsource:
  category: antivirus
detection:
  selection:
    Filename|contains: '\spool\drivers\x64\'
  keywords:
    - 'Suspicious.Cloud.7.EP'
    - 'Suspicious.Cloud.9.EP'
  condition: selection and not keywords
falsepositives:
  - Legitimate vendor-supplied printer driver updates or installations that
    write signed DLLs into the Print Spooler x64 driver directory through
    an approved printer management workflow, triggering heuristic AV
    detections before the file is classified by the vendor's cloud backend.
level: critical
