# Arquivo: A.yml
title: PowerShell Execution from Alternate Host
id: c3d4e5f6-a7b8-49c0-1d2e-3f4a5b6c7d8e
status: experimental
description: Detects PowerShell execution from non-default hosts (e.g., custom executables embedding the PowerShell runtime) logged via the HostApplication field, bypassing detections focused on powershell.exe.
references:
    - https://threathunterplaybook.com/hunts/windows/190815-RemoteServiceInstallation/notebook.html
author: Senior Threat Detection Engineer
date: 2026-06-08
logsource:
    product: windows
    category: ps_classic_start
detection:
    selection:
        Data|contains: 'HostApplication='
    filter_main_ps_paths:
        Data|contains:
            - '\System32\WindowsPowerShell\v1.0\powershell.exe'
            - '\SysWOW64\WindowsPowerShell\v1.0\powershell.exe'
            - '/System32/WindowsPowerShell/v1.0/powershell.exe'
            - '/SysWOW64/WindowsPowerShell/v1.0/powershell.exe'
            - '\System32\WindowsPowerShell\v1.0\powershell.exe'
    filter_main_sdiagnhost:
        Data|contains: '\System32\sdiagnhost.exe'
    filter_main_bare_powershell:
        Data|contains: 'powershell'
    filter_optional_citrix:
        Data|contains: 'Citrix.ConfigSync.CommandHost.exe'
    filter_optional_hexnode:
        Data|contains: 'Hexnode Agent\bin\HexnodeAgent.exe'
    condition: selection and not 1 of filter_main_* and not 1 of filter_optional_*
falsepositives:
    - Legitimate third-party applications that embed PowerShell runtime (e.g., Citrix, Hexnode) — excluded via optional filters; other custom applications may require additional tuning
level: medium
tags:
    - attack.execution
    - attack.t1059.001
    - attack.defense_evasion
    - attack.t1036.003

# Arquivo: B.yml
title: PowerShell Execution From Alternate Host Applications
id: 6a4f2d1b-8c3e-4f7a-9b2d-0e1f2a3c4d5e
status: experimental
description: Detects PowerShell engine starts where the HostApplication is an alternate (non-default) host executable. Attackers embed the PowerShell runtime inside custom executables to bypass detections focused on powershell.exe. Matches the HostApplication marker from classic PowerShell event logging and excludes known legitimate hosts and updaters.
author: Senior Threat Detection Engineer
date: 2026/06/13
references:
  - [https://threathunterplaybook.com/hunts/windows/190815-RemoteServiceInstallation/notebook.html](https://threathunterplaybook.com/hunts/windows/190815-RemoteServiceInstallation/notebook.html)
tags:
  - attack.defense_evasion
  - living-off-the-land
  - windows
  - powershell
logsource:
  product: windows
  category: ps_classic_start
  description: Classic PowerShell engine start events (PowerShell classic event logging). Ensure the HostApplication field from the event Data is collected.
detection:
  selection:
    HostApplication|endswith:
      - '.exe'
      - '.EXE'
  filter_main_paths:
    HostApplication|contains:
      - 'WindowsPowerShell\\v1.0\\powershell.exe'
      - 'WindowsPowerShell/v1.0/powershell.exe'
      - 'SysWOW64\\WindowsPowerShell\\v1.0\\powershell.exe'
      - 'SysWOW64/WindowsPowerShell/v1.0/powershell.exe'
      - '\\Windows\\System32\\WindowsPowerShell\\v1.0\\powershell.exe'
      - '/Windows/System32/WindowsPowerShell/v1.0/powershell.exe'
      - '\\Windows\\SysWOW64\\WindowsPowerShell\\v1.0\\powershell.exe'
      - '/Windows/SysWOW64/WindowsPowerShell/v1.0/powershell.exe'
      - 'sdiagnhost.exe'
      - 'SdiagnHost.exe'
      - 'powershell'
      - 'PowerShell'
  filter_optional_thirdparty:
    HostApplication|contains:
      - 'ConfigSync'
      - 'Citrix.ConfigSync'
      - 'Hexnode'
      - 'HexnodeAgent'
  condition: selection and not 1 of filter_main_paths and not 1 of filter_optional_thirdparty
falsepositives:
  - Legitimate third-party products that embed PowerShell for automation (e.g., management agents) not listed in optional filters.
  - Custom internal tooling that intentionally hosts PowerShell for orchestration or automation.
level: high

# Arquivo: C.yml
title: PowerShell Execution from Non-Standard Host Application
id: 9c2e7f4b-1d3a-4f8e-b7c2-6e4a1d9f3c58
status: experimental
description: >
  Detects PowerShell engine invocations where the HostApplication recorded
  in the classic PowerShell event log is not one of the standard Microsoft
  PowerShell binaries. The HostApplication field identifies the process that
  loaded the PowerShell runtime; under normal conditions this is powershell.exe
  or powershell_ise.exe in their canonical System32 or SysWOW64 paths.
  Adversaries and C2 frameworks such as SilentTrinity, Empire, and Covenant
  embed the PowerShell runtime (System.Management.Automation.dll) directly
  inside a custom executable, causing all PowerShell activity to be logged
  under the attacker-controlled host process name rather than powershell.exe.
  This technique bypasses detections and allow-list policies that focus
  exclusively on the powershell.exe binary. Detection matches the
  HostApplication marker in the Data field and then excludes all known
  legitimate host paths across both architecture variants, the Windows
  diagnostic host, and third-party products known to legitimately embed
  the PowerShell runtime.
references:
  - https://threathunterplaybook.com/hunts/windows/190815-RemoteServiceInstallation/notebook.html
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.defense_evasion
  - attack.execution
  - attack.t1059.001
  - attack.t1027
logsource:
  category: ps_classic_start
  product: windows
detection:
  selection:
    Data|contains: 'HostApplication='
  filter_main_default_paths:
    Data|contains:
      - 'HostApplication=C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe'
      - 'HostApplication=C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe'
      - 'HostApplication=C:\Windows\System32\WindowsPowerShell\v1.0\powershell_ise.exe'
      - 'HostApplication=C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell_ise.exe'
      - 'HostApplication=C:/Windows/System32/WindowsPowerShell/v1.0/powershell.exe'
      - 'HostApplication=C:/Windows/SysWOW64/WindowsPowerShell/v1.0/powershell.exe'
  filter_main_diagnostic:
    Data|contains:
      - 'HostApplication=C:\Windows\System32\sdiagnhost.exe'
      - 'HostApplication=powershell'
  filter_optional_third_party:
    Data|contains:
      - 'HostApplication=C:\Program Files\Citrix\ConfigSync\ConfigSync.exe'
      - 'HostApplication=C:\Program Files (x86)\Hexnode\MDM Agent\HexnodeMDMAgent.exe'
  condition: selection and not 1 of filter_main_* and not 1 of filter_optional_*
falsepositives:
  - Legitimate third-party software products that embed the PowerShell
    runtime for configuration or management purposes and are not covered
    by the optional filter group; add newly discovered hosts to the
    filter_optional_third_party block after confirming legitimacy.
  - In-house automation or DevOps tooling built on the PowerShell SDK
    that invokes the runtime from a custom host process as part of an
    approved internal platform.
level: high
