  - [https://thecyberexpress.com/ukraine-hit-by-meshagent-malware-campaign/](https://thecyberexpress.com/ukraine-hit-by-meshagent-malware-campaign/)
tags:
  - attack.persistence
  - attack.remote_services
  - malware.meshagent
logsource:
  product: macos
  category: process_creation
  description: Process creation events from macOS endpoint telemetry (e.g., sysmon for macOS, osquery, or native process auditing) that include the full CommandLine. Ensure process auditing is enabled and command-line arguments are captured.
detection:
  selection:
    CommandLine|contains:
      - '--install'
      - '-install'
  condition: selection
falsepositives:
  - Legitimate software installers or management agents that use --install or -install flags.
  - Developer or build tools invoked with install-style arguments during packaging or CI workflows.
