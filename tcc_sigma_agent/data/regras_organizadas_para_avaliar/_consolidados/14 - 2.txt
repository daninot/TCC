# Arquivo: A.yml
title: CVE-2023-1389 TP-Link Archer AX21 Command Injection Exploit Attempt
id: f4b8d2c1-3e7a-4f9b-a6d4-8c1e5b3f7a29
status: experimental
description: >
  Detects HTTP requests targeting the unauthenticated command injection
  vulnerability CVE-2023-1389 in the TP-Link Archer AX21 router web
  management interface, as actively exploited by Mirai botnet variants.
  The vulnerability resides in the locale API endpoint where the country
  form field is passed directly into a shell command via popen without
  sanitisation, allowing unauthenticated remote code execution. Mirai
  operators exploit this to inject a wget or curl command into the country
  parameter, causing the router to download and execute architecture-specific
  Mirai payloads. The ZDI threat-hunting team observed active exploitation
  from Eastern Europe beginning April 11 2023, shortly after TP-Link
  released a firmware patch in March 2023. Detection requires both the
  vulnerable CGI endpoint URI fragments and the write operation payload
  indicator to be present simultaneously, reducing false positives from
  unrelated CGI management traffic.
references:
  - https://www.tenable.com/security/research/tra-2023-11
  - https://github.com/Voyag3r-Security/CVE-2023-1389/blob/4ecada7335b17bf543c0e33b2c9fb6b6215c09ae/archer-rev-shell.py
  - https://www.zerodayinitiative.com/blog/2023/4/21/tp-link-wan-side-vulnerability-cve-2023-1389-added-to-the-mirai-botnet-arsenal
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.initial_access
  - attack.t1190
  - cve.2023-1389
  - detection.emerging_threats
logsource:
  category: proxy
detection:
  selection_http:
    cs-method:
      - GET
      - POST
    c-uri|contains|all:
      - '/cgi-bin/luci/'
      - 'locale'
  selection_payload:
    c-uri|contains:
      - 'operation=write'
      - 'country='
  condition: selection_http and selection_payload
falsepositives:
  - Legitimate administrative access to a TP-Link management interface
    where a network administrator issues a valid locale write operation
    to configure the country or region setting through the web UI and
    that traffic is routed through a monitored proxy. Any match in a
    production environment should be investigated and the source IP
    verified against authorised administrator hosts before dismissal.
level: high
