# Arquivo: D.yml
title: Bitbucket - Secret Detected in Repository Push
id: 7c3e1a9f-84b2-4d56-a031-fc29e8d50712
status: experimental
description: |
    Detects when the Bitbucket secret scanning engine finds a leaked
    secret (password, token, API key, private key, etc.) inside a
    repository commit push. The event is recorded in the audit log
    at Base coverage level (Security > Security category).
    Any match should be treated as a potential credential exposure.
references:
    - https://confluence.atlassian.com/bitbucketserver/secret-scanning-1157471613.html
    - https://confluence.atlassian.com/bitbucketserver/audit-log-events-776640423.html
author: Security Team
date: 2026-05-25
tags:
    - attack.credential_access
    - attack.t1552
    - attack.t1552.001
logsource:
    product: bitbucket
    category: audit
detection:
    selection:
        auditType.action: 'Secret detected'
    selection_i18n:
        auditType.actionI18nKey: 'bitbucket.secretscanning.audit.action.secretdetected'
    condition: 1 of selection*
fields:
    - auditType.action
    - initiatingUser
    - commitId
    - path
    - line
    - ruleId
falsepositives:
    - Test or sandbox repositories with intentional dummy secrets
    - Overly permissive scanning regex causing false positives
    - Migration of legacy repositories with known historical exposure
level: high

# Arquivo: E.yml
title: Bitbucket Secret Scanning Configuration Modified
id: 59aef46e-1da5-429a-840f-7b7e3bd260a9
status: experimental
description: Detects global, project, or repository-level modifications to Bitbucket secret scanning rules and allowlists. Unauthorized deletion or relaxation of these patterns allows credentials to pass into source control blindly.
references:
    - https://confluence.atlassian.com/bitbucketserver/audit-log-events-776640423.html
    - https://confluence.atlassian.com/bitbucketserver/secret-scanning-1157471613.html
author: Security Operations Center
date: 2026/05/25
tags:
    - attack.defense_evasion
    - attack.t1562.001 # Impair Defenses: Disable or Modify Tools
logsource:
    product: bitbucket
    service: audit
detection:
    selection_actions:
        auditType.action:
            - 'Global secret scanning deleted'
            - 'Global secret scanning rule created'
            - 'Global secret scanning rule updated'
            - 'Repository secret scanning rule created'
            - 'Repository secret scanning rule deleted'
            - 'Repository secret scanning rule updated'
            - 'Repository secret scanning allowlist rule added'
            - 'Repository secret scanning allowlist rule deleted'
            - 'Repository secret scanning allowlist rule updated'
    condition: selection_actions
falsepositives:
    - Legitimate configuration adjustments, false-positive reductions, and allowlist updates carried out by authorized DevOps teams or Security Administrators.
level: medium
