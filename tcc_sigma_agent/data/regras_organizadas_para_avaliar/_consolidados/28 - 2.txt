# Arquivo: B.yml
title: PsExec Default Named Pipe Creation Detected
id: 2d9f4b6a-7c3e-4a1f-8b2d-5e6c7a9b0f2e
status: experimental
description: Detects creation of the default PsExec named pipe on Windows hosts. Creation of the PsExec service pipe is a strong indicator of PsExec usage for remote command execution or lateral movement. Requires Sysmon named pipe event logging (Event ID 17/18) to be enabled and collected.
author: Senior Threat Detection Engineer
date: 2026/06/06
references:
  - [https://www.jpcert.or.jp/english/pub/sr/ir_research.html](https://www.jpcert.or.jp/english/pub/sr/ir_research.html)
  - [https://jpcertcc.github.io/ToolAnalysisResultSheet](https://jpcertcc.github.io/ToolAnalysisResultSheet)
tags:
  - attack.lateral_movement
  - attack.remote_services
  - attack.t1021
  - windows
  - sysmon
logsource:
  product: windows
  category: pipe_created
  description: Sysmon named pipe events must be enabled (Event ID 17 Pipe Created and Event ID 18 Pipe Connected) and forwarded to the SIEM.
detection:
  selection:
    EventID|in:
      - 17
      - 18
    PipeName|endswith:
      - '\\\\.\\pipe\\svcctl'
      - '\\\\.\\pipe\\PSEXESVC'
      - '\\\\.\\pipe\\psexesvc'
      - '\\\\.\\pipe\\PSEXESVC_SERVICE'
  condition: selection
falsepositives:
  - Legitimate administrative use of PsExec by IT or remote management tooling.
  - Security or automation tooling that intentionally creates or connects to PsExec-compatible pipes.
level: high
