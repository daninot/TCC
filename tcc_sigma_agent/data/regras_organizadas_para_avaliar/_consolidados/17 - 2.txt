# Arquivo: E.yml
This is a legitimate defensive detection engineering request. Let me fetch the actual audit log actions reference for the specific deletion action strings.  The confirmed GitHub audit log action strings for deletion events are `codespaces.delete`, `environment.delete`, `project.delete`, and `repo.destroy`, with the `action` field as the structured key in streamed audit log events.

title: GitHub Audit Log Delete Action Invoked on Critical Resource
id: 4e2b8f3a-7c1d-4a9e-b5f3-1d8c2e4a7b96
status: experimental
description: >
  Detects delete actions recorded in the GitHub organization audit log
  targeting codespaces, deployment environments, projects, and repositories.
  These four action strings represent the highest-impact destructive
  operations available to organization members: repo.destroy permanently
  removes a repository and all its history; project.delete eliminates a
  project board and associated metadata; environment.delete removes a
  deployment environment and its associated secrets and protection rules;
  and codespaces.delete terminates a cloud development environment.
  When performed outside an approved change-management workflow — or by
  an account that should not hold the necessary permissions — these
  actions indicate insider threat activity, a compromised developer or
  admin account conducting a destructive attack, or an adversary preparing
  the environment by removing security controls or audit artifacts prior
  to further activity. Repository and environment deletion can also be
  used to disrupt CI/CD pipelines or destroy the forensic record of
  prior malicious commits. Requires GitHub audit log streaming to be
  enabled and the event stream forwarded to the SIEM. Setup documentation:
  https://docs.github.com/en/enterprise-cloud@latest/admin/monitoring-activity-in-your-enterprise/reviewing-audit-logs-for-your-enterprise/streaming-the-audit-log-for-your-enterprise#setting-up-audit-log-streaming
references:
  - https://docs.github.com/en/organizations/keeping-your-organization-secure/managing-security-settings-for-your-organization/reviewing-the-audit-log-for-your-organization#audit-log-actions
  - https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/security-log-events#codespaces
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:

  - attack.t1213.003

    Requirements: GitHub audit log streaming must be enabled for the

    https://docs.github.com/en/enterprise-cloud@latest/admin/monitoring-activity-in-your-enterprise/reviewing-audit-logs-for-your-enterprise/streaming-the-audit-log-for-your-enterprise#setting-up-audit-log-streaming
