# Arquivo: A.yml
title: Suspicious Registry Query Activity (T1012)
id: 1c9f4b2e-2026-t1012-registry-query
status: experimental
description: Detects processes and command lines commonly used to query Windows registry keys and values (reg.exe queries, PowerShell registry cmdlets, WMI StdRegProv calls, and common scripting patterns). Frequent or unexpected registry enumeration from non-admin users, from uncommon parent processes, or via encoded/obfuscated command lines may indicate discovery activity consistent with ATT&CK T1012.
author: Daniela
date: 2026-06-07
references:
  - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md
logsource:
  product: windows
  service: sysmon
  category: process_creation
detection:
  selection_reg_query:
    EventID: 1
    Image|re:
      - '(?i)\\reg\.exe$'
    CommandLine|re:
      - '(?i)\bquery\b'
      - '(?i)\bquery\s+HKLM\\'
      - '(?i)\bquery\s+HKCU\\'
  selection_powershell_registry_cmdlets:
    EventID: 1
    Image|re:
      - '(?i)\\powershell\.exe$'
      - '(?i)\\pwsh\.exe$'
    CommandLine|re:
      - '(?i)Get-ItemProperty\b'
      - '(?i)Get-Item\b\s+HKLM:|HKCU:'
      - '(?i)Get-ChildItem\s+HKLM:|HKCU:'
      - '(?i)Get-ItemPropertyValue\b'
      - '(?i)Get-ItemPropertyValue\s+-Path'
      - '(?i)Get-ItemProperty\s+-Path'
  selection_powershell_wmi_stdregprov:
    EventID: 1
    Image|re:
      - '(?i)\\powershell\.exe$'
      - '(?i)\\pwsh\.exe$'
    CommandLine|re:
      - '(?i)StdRegProv'
      - '(?i)Get-WmiObject\s+.*StdRegProv'
      - '(?i)Get-CimInstance\s+.*StdRegProv'
      - '(?i)Invoke-WmiMethod\s+.*StdRegProv'
  selection_wmic_reg:
    EventID: 1
    Image|re:
      - '(?i)\\wmic\.exe$'
    CommandLine|re:
      - '(?i)reg(istry)?'
  selection_encoded_hklm_hkcu:
    EventID: 1
    CommandLine|re:
      - '(?i)-EncodedCommand\s+[A-Za-z0-9+/=]{80,}'
      - '(?i)(HKLM:|HKCU:|HKEY_LOCAL_MACHINE|HKEY_CURRENT_USER)'
  selection_suspicious_parent:
    EventID: 1
    ParentImage|re:
      - '(?i)\\(winword|excel|powerpnt|outlook|msedge|chrome|firefox|svchost|explorer)\.exe$'
  selection_high_frequency:
    EventID: 1
    CommandLine|re:
      - '(?i)(HKLM:|HKCU:|HKEY_LOCAL_MACHINE|HKEY_CURRENT_USER)'
    CountByProcessImage: ">10"
    Timeframe: "5m"
  condition: (selection_reg_query or selection_powershell_registry_cmdlets or selection_powershell_wmi_stdregprov or selection_wmic_reg or selection_encoded_hklm_hkcu) and (selection_suspicious_parent or selection_high_frequency)
fields:
  - timestamp
  - ComputerName
  - SubjectUserName
  - Image
  - ParentImage
  - CommandLine
  - ProcessId
  - CountByProcessImage
falsepositives:
  - Legitimate administrative scripts, inventory/asset management tools, or endpoint management agents that query registry keys (whitelist known management accounts and hosts).
  - Backup or configuration management tasks that enumerate registry state as part of normal operations.
level: medium
tags:
  - attack.discovery
  - attack.T1012
  - discovery.registry
  - detection.windows.sysmon
notes: |
  - Tuning: whitelist known automation and management tooling; restrict detection to non-admin users, unusual parent processes, or unexpected hosts to reduce noise.
  - Investigation: collect full command line, parent/child process tree, account context, and correlate with other discovery activity (network scans, file system enumeration). Search for subsequent persistence or credential-access attempts after registry enumeration.
  - Mitigation: limit unnecessary registry read access for non-privileged accounts, monitor and alert on high-frequency registry enumeration, and enforce application control for scripting hosts.

# Arquivo: B.yml
title: System Registry Configuration Discovery Via Reg.exe
id: c71f844f-d007-4e6f-a63e-b49b251ce7bf
status: test
description: Detects the execution of 'reg.exe' to query specific registry keys commonly targeted by adversaries (and simulated by Atomic Red Team) to discover installed software, startup persistence mechanisms, services, and system security configurations.
references:
    - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md
author: Security Operations Center
date: 2026/06/07
tags:
    - attack.discovery
    - attack.t1012 # Query Registry
logsource:
    category: process_creation
    product: windows
detection:
    selection_image:
        - Image|endswith: '\reg.exe'
        - OriginalFileName: 'reg.exe'
    selection_action:
        CommandLine|contains: ' query '
    selection_keys:
        CommandLine|contains:
            - '\Software\Microsoft\Windows\CurrentVersion\Uninstall'
            - '\Software\Microsoft\Windows\CurrentVersion\Run'
            - '\Software\Microsoft\Windows\CurrentVersion\Internet Settings'
            - '\System\CurrentControlSet\Services\'
            - '\System\CurrentControlSet\Control\Lsa'
            - '\System\CurrentControlSet\Control\Terminal Server'
    condition: selection_image and selection_action and selection_keys
falsepositives:
    - Legitimate system administration scripts or IT inventory management software (e.g., SCCM, Lansweeper) periodically querying registry keys for software asset auditing or compliance checks.
    - Software installers validating prerequisite configurations or checking for existing installations before execution.
level: medium

# Arquivo: D.yml
title: Windows - Registry Persistence Mechanism Enumeration via reg.exe (T1012)
id: 7c3a9e21-4f85-4b67-d092-1e8c4b9f3a57
status: test
description: |
    Detects systematic enumeration of Windows persistence mechanism registry keys
    using reg.exe, matching the exact key set queried in Atomic Red Team T1012
    Atomic Test #1.

    Adversaries query these keys during post-compromise discovery to understand
    what persistence mechanisms exist in the environment and to identify their
    own planted entries. The key set covers all major auto-start extensibility
    points (ASEPs) and logon hooks:

    1. selection_run_keys — HKLM/HKCU Run, RunOnce, RunServicesOnce,
       RunServices and Explorer\Run policy keys. These are the primary
       registry-based persistence locations; querying all variants together
       indicates systematic ASEP enumeration rather than a targeted lookup.

    2. selection_winlogon_keys — Winlogon Notify, Userinit, and Shell subkeys.
       Legitimate processes rarely query all three Winlogon subkeys consecutively;
       this pattern is characteristic of post-exploitation discovery frameworks
       (Cobalt Strike, Metasploit, LOLBAS scripts) profiling the system.

    3. selection_service_driver_enum — reg.exe querying the services hive
       recursively (/s) combined with findstr filtering for .sys ImagePaths.
       This is the specific pattern from the atomic test for enumerating
       kernel driver paths — used to identify candidate DLL-search-order or
       driver hijacking targets.

    Note: individual queries of Run keys are common and low-signal. This rule
    gains value when correlated: the same process or session issuing queries
    across multiple selections in a short window strongly indicates automated
    discovery tooling rather than manual administration.
references:
    - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md
    - https://attack.mitre.org/techniques/T1012/
    - https://blog.cylance.com/windows-registry-persistence-part-2-the-run-keys-and-search-order
    - https://www.offensive-security.com/wp-content/uploads/2015/04/wp.Registry_Quick_Find_Chart.en_us.pdf
author: Security Team
date: 2026-06-07
tags:
    - attack.discovery
    - attack.t1012           # Query Registry
    - attack.t1547.001       # Boot/Logon Autostart: Registry Run Keys (keys being profiled)
    - attack.t1547.004       # Boot/Logon Autostart: Winlogon Helper DLL (keys being profiled)
logsource:
    category: process_creation
    product: windows
detection:
    selection_reg_query_base:
        # reg.exe must be the executing image and 'query' must be present
        Image|endswith: '\reg.exe'
        CommandLine|contains: 'query'
    selection_run_keys:
        # HKLM/HKCU Run family — primary ASEP locations from the atomic test
        CommandLine|contains:
            - '\CurrentVersion\Run'             # Run, RunOnce, RunOnceEx
            - '\CurrentVersion\RunServices'     # RunServices, RunServicesOnce
            - '\Policies\Explorer\Run'          # Group Policy enforced Run keys
            - 'ShellServiceObjectDelayLoad'     # SSODL — Shell extension persistence
    selection_winlogon_keys:
        # Winlogon subkeys — logon hook and session persistence locations
        CommandLine|contains:
            - 'Winlogon\Notify'
            - 'Winlogon\Userinit'
            - 'Winlogon\\Shell'                 # double backslash as in the atomic test
            - 'Winlogon/Shell'
    selection_service_driver_enum:
        # Specific atomic test pattern: recursive services query piped to findstr .sys
        # "reg query HKLM\system\currentcontrolset\services /s | findstr ImagePath"
        CommandLine|contains|all:
            - '\currentcontrolset\services'
            - '/s'
    filter_sysadmin_tools:
        # Suppress known legitimate administrative tools that read Run/Winlogon keys
        # Populate with your environment's known-good management processes:
        # ParentImage|endswith:
        #     - '\mmc.exe'          # Group Policy Management Console
        #     - '\regedit.exe'      # Manual registry editing
        #     - '\autoruns.exe'     # Sysinternals Autoruns (legitimate auditing)
        #     - '\autorunsc.exe'    # Sysinternals Autoruns CLI
        Image: null   # placeholder — populate with authorized admin tools
    condition: >
        selection_reg_query_base and
        (1 of selection_run_keys or
         1 of selection_winlogon_keys or
         selection_service_driver_enum)
        and not filter_sysadmin_tools
fields:
    - Image
    - CommandLine
    - ParentImage
    - ParentCommandLine
    - User
    - ProcessId
falsepositives:
    - Sysinternals Autoruns / Autorunsc.exe performing authorized persistence audits
    - Enterprise management agents (SCCM, Tanium) inventorying startup configurations
    - Security scanners performing baseline registry auditing
    - IT administrators manually querying Run keys during troubleshooting sessions
level: medium

    - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md

    category: process_creation

    selection_img:
        - Image|endswith: '\reg.exe'

            - 'HKCU\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell'
            - 'HKLM\Software\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell'
            - 'HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\ShellServiceObjectDelayLoad'
            - 'HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnce'
            - 'HKLM\Software\Microsoft\Windows\CurrentVersion\RunOnceEx'
            - 'HKLM\Software\Microsoft\Windows\CurrentVersion\Run'
            - 'HKCU\Software\Microsoft\Windows\CurrentVersion\Run'
            - 'HKCU\Software\Microsoft\Windows\CurrentVersion\RunOnce'
            - 'HKLM\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\Run'
            - 'HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer\Run'

    - Legitimate system administration or software installation queries
