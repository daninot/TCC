title: Kerberos Unconstrained Delegation Exposure Detection
id: 2c5c6c9f-7d8f-4b8d-9b4d-1f6c8e9a2b11
status: experimental
description: >
  Detects Active Directory accounts or computer objects configured with
  Kerberos Unconstrained Delegation. Systems trusted for unconstrained
  delegation can cache user TGTs in LSASS and may enable privilege
  escalation, lateral movement, or full domain compromise if the host
  is compromised.
references:
  - https://adsecurity.org/?p=3458
  - https://adsecurity.org/?p=1667
author: OpenAI
date: 2026-05-25
tags:
  - attack.credential_access
  - attack.lateral_movement
  - attack.privilege_escalation
  - attack.t1558
  - attack.t1550
  - attack.t1134
logsource:
  product: windows
  service: security
definition: >
  Requires Active Directory object change auditing and ingestion of
  directory service changes or account configuration events.
detection:
  selection_uac_flag:
    AttributeLDAPDisplayName: "userAccountControl"
    AttributeValue|contains:
      - "TRUSTED_FOR_DELEGATION"
      - "0x80000"
  selection_delegation_change:
    OperationType:
      - "Value Added"
      - "%%14674"
  condition: selection_uac_flag and selection_delegation_change
fields:
  - SubjectUserName
  - ObjectDN
  - ObjectClass
  - AttributeLDAPDisplayName
  - AttributeValue
  - OperationType
falsepositives:
  - Legacy applications requiring Kerberos double-hop authentication
  - Misconfigured service accounts
  - Authorized delegation changes during application deployment
level: high

# Arquivo: C.yml
title: Active Directory - Kerberoasting TGS RC4 Encryption Request
id: 3c4a7e9d-f521-4b08-a6f1-82de05c93447
status: test
description: |
    Detects Kerberoasting activity via Event ID 4769: a Kerberos TGS
    service ticket request where the encryption type is RC4 (0x17)
    and TicketOptions matches 0x40810000 — the bit pattern emitted by
    common Kerberoasting tools (Invoke-Kerberoast, Rubeus, GetUserSPNs).
    In modern Windows environments (Vista+) TGS tickets are AES-encrypted
    (0x12). An RC4 request for a user-backed SPN indicates a deliberate
    downgrade to allow offline NTLM hash cracking of service account
    passwords. Computer accounts (ServiceName ending in '$') are filtered
    because Windows auto-generates 128-char passwords for them, making
    cracking infeasible and generating significant noise.
references:
    - https://adsecurity.org/?p=3458
    - https://attack.mitre.org/techniques/T1558/003/
    - https://www.ultimatewindowssecurity.com/securitylog/encyclopedia/event.aspx?eventid=4769
author: Security Team
date: 2026-05-25
tags:
    - attack.credential_access
    - attack.t1558       # Steal or Forge Kerberos Tickets
    - attack.t1558.003   # Kerberoasting
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 4769
        TicketEncryptionType: '0x17'
        TicketOptions: '0x40810000'
        Status: '0x0'
    filter_computer_accounts:
        ServiceName|endswith: '$'   # computer, trust & MSA accounts
    filter_krbtgt:
        ServiceName|contains: 'krbtgt'  # normal TGT renewal noise
    condition: selection and not 1 of filter_*
fields:
    - AccountName
    - ServiceName
    - TicketEncryptionType
    - TicketOptions
    - IpAddress
    - IpPort
    - Status
falsepositives:
    - Legacy services that only support RC4 Kerberos (e.g., NetApp, older MIT Kerberos clients)
    - Inter-forest Kerberos trust tickets when AES is not enabled on the trust
    - Security team tooling performing authorized Kerberoast assessments
level: high

# Arquivo: D.yml
title: Kerberos Golden Ticket Detection
id: 7c2f9e8a-4d1e-11ef-9a2d-0242ac120002
status: experimental
description: Detects potential Kerberos Golden Ticket usage in Active Directory by monitoring suspicious ticket requests and anomalies.
author: Copilot
date: 2026/05/25
references:
  - https://adsecurity.org/?p=3458
logsource:
  product: windows
  service: security
  category: authentication
detection:
  selection_ticket_anomalies:
    EventID:
      - 4769   # Kerberos service ticket requested
      - 4771   # Kerberos pre-authentication failed
      - 4624   # Successful logon
    TicketEncryptionType:
      - "0x17"   # RC4-HMAC (legacy, often abused in Golden Tickets)
    ServiceName|contains:
      - "$"      # Computer accounts targeted
  selection_suspicious_accounts:
    AccountName|contains:
      - "krbtgt"
  condition: selection_ticket_anomalies or selection_suspicious_accounts
fields:
  - timestamp
  - EventID
  - AccountName
  - ServiceName
  - TicketEncryptionType
  - IPAddress
falsepositives:
  - Legacy systems using RC4 encryption
  - Misconfigured service accounts
level: critical
tags:
  - attack.credential_access
  - attack.t1558.001

# Arquivo: E.yml
title: Potential Kerberoasting Activity via RC4 Ticket Requests
id: d13b91fa-40f2-4b21-8278-656faef6934c
status: experimental
description: Detects when a user requests a Kerberos Ticket Granting Service (TGS) ticket using legacy RC4 encryption (0x17). This behavior is heavily leveraged in Kerberoasting attacks to extract service account ticket hashes for offline password cracking.
references:
    - https://adsecurity.org/?p=3458
author: Security Operations Center
date: 2026/05/25
tags:
    - attack.credential_access
    - attack.t1558.003 # Steal or Forge Kerberos Tickets: Kerberoasting
logsource:
    product: windows
    service: security
detection:
    selection:
        EventID: 4769 # A Kerberos service ticket was requested
        TicketEncryptionType: '0x17' # RC4-HMAC
        Status: '0x0' # Audit Success
    filter_computers:
        ServiceName|endswith: '$' # Filter out default machine/trust accounts
    condition: selection and not filter_computers
falsepositives:
    - Legacy corporate applications or older non-Windows systems (e.g., legacy NAS appliances or outdated Samba versions) that fail to support AES-128/AES-256 and fallback to RC4.
level: medium
