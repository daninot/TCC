# Arquivo: C.yml
title: Duo MFA Authentication Using Bypass Code
id: 4e2b7f1a-9c3d-4b6e-8a1f-2d3c4b5e6f7a
status: experimental
description: Detects successful Duo MFA authentications where the authentication reason indicates a bypass code was used. Bypass codes are temporary admin-issued passcodes intended as backup credentials; their use can indicate abuse by attackers or social-engineered support interactions that defeat MFA protections. Requires Duo authentication log ingestion with eventType, result/outcome, and reason fields.
author: Senior Threat Detection Engineer
date: 2026/06/12
references:
  - [https://duo.com/docs/adminapi#logs](https://duo.com/docs/adminapi#logs)
  - [https://help.duo.com/s/article/6327?language=en_US](https://help.duo.com/s/article/6327?language=en_US)
tags:
  - identity
  - mfa
  - duo
  - tampering
  - account_takeover
logsource:
  product: cisco
  service: duo
  category: identity_management
  description: Duo authentication events from the Duo Admin API or SIEM integration. Events must include eventType (or action), result/outcome, actor, target, and reason fields.
detection:
  selection_event:
    eventType|in:
      - 'authentication_success'
      - 'authentication'
      - 'auth'
  selection_result:
    result|in:
      - 'SUCCESS'
      - 'success'
      - 'allow'
      - 'ALLOW'
    outcome|in:
      - 'SUCCESS'
      - 'success'
  selection_reason:
    reason|contains:
      - 'bypass'
      - 'bypass code'
      - 'bypass_code'
      - 'bypass-code'
      - 'temporary passcode'
      - 'admin passcode'
  condition: selection_event and selection_result and selection_reason
fields:
  - eventType
  - timestamp
  - actor.username
  - actor.displayName
  - target.username
  - target.displayName
  - result
  - reason
  - ip
falsepositives:
  - Legitimate use of admin-issued bypass codes by helpdesk or support during verified account recovery.
  - Emergency or documented operational procedures where bypass codes are intentionally used.
level: high

title: Cisco Duo Successful MFA Authentication Via Bypass Code
id: 6f7e1c10-2dc9-4312-adb6-9574ff09a5c8
status: test
description: |
    Detects when a successful MFA authentication occurs due to the use of a bypass code.
    A bypass code is a temporary passcode created by an administrator for a specific user to access a Duo-protected application. These are generally used as "backup codes," so that enrolled users who are having problems with their mobile devices (e.g., mobile service is disrupted, the device is lost or stolen, etc.) or who temporarily can't use their enrolled devices (on a plane without mobile data services) can still access their Duo-protected systems.
references:
    - https://duo.com/docs/adminapi#logs
    - https://help.duo.com/s/article/6327?language=en_US
author: Nikita Khalimonenkov
date: 2024-04-17

    - attack.credential-access
    - attack.initial-access
    - attack.stealth
logsource:
    product: cisco
    service: duo
detection:
    selection:
        event_type: authentication
        reason: bypass_user
    condition: selection
falsepositives:
    - Legitimate user that was assigned on purpose to a bypass group
level: medium
