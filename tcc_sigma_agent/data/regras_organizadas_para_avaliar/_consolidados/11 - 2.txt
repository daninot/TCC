# Arquivo: B.yml
title: Exchange PowerShell Cmdlet History Log File Deleted
id: a3c8f1e7-2d4b-4f9c-b6e2-5d1a7f3c8b42
status: experimental
description: >
  Detects the deletion of Exchange PowerShell cmdlet history log files from
  the Exchange Server CmdletInfra LocalPowerShell logging directory. Every
  command executed through the Exchange Management Shell is written to this
  directory as a structured log file whose name encodes the invoking process,
  PID, the Cmdlet marker, and a timestamp. These files provide a persistent
  forensic record of every cmdlet, authenticated user, parameters, and
  execution result. Adversaries with administrative access to an Exchange
  Server — including those who have already purged the MSExchangeManagement
  Windows event log — may target these flat files to eliminate the secondary
  audit trail and frustrate incident-response timeline reconstruction. The
  detection requires both the canonical directory path prefix and the Cmdlet
  filename token to be present simultaneously, so that unrelated file
  deletions in adjacent Exchange log directories do not produce false
  positives. Requires Sysmon Event ID 23 (FileDelete) or an equivalent
  file-system telemetry source to be deployed and forwarding events to
  the SIEM.
references:
  - https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.defense_evasion
  - attack.t1070.004
logsource:
  category: file_delete
  product: windows
detection:
  selection:
    TargetFilename|startswith: 'C:\Program Files\Microsoft\Exchange Server\V15\Logging\CmdletInfra\LocalPowerShell\Cmdlet'
    TargetFilename|contains: '_Cmdlet_'
  condition: selection
falsepositives:
  - Exchange Server built-in log rotation and disk-quota enforcement
    processes that periodically remove aged CmdletInfra log files in
    accordance with the configured logging retention policy.
  - Enterprise backup agents or archival scripts that stage log files
    to secondary storage and then delete the originals as part of an
    approved data-retention workflow.
  - Exchange cumulative update or repair procedures that temporarily
    remove or recreate log directories during installation.
level: high

# Arquivo: D.yml
title: Deletion of Exchange PowerShell Cmdlet History Logs
id: e2a7f9b4-5c3d-4a6b-9f8e-1b2c3d4e5f60
status: experimental
description: Detects file deletion events that target Exchange Server PowerShell/Exchange cmdlet logging directories and filenames associated with cmdlet history or cmdlet logs. This may indicate an attempt to remove forensic evidence of administrative or malicious cmdlet execution. Requires file deletion auditing to be enabled on the host.
author: Senior Threat Detection Engineer
date: 2026/06/02
references:
  - [https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/](https://m365internals.com/2022/10/07/hunting-in-on-premises-exchange-server-logs/)
tags:
  - attack.defense_evasion
  - attack.persistence
  - detection
logsource:
  product: windows
  category: file_delete
detection:
  selection_path:
    TargetFilename|startswith:
      - 'C:\\Program Files\\Microsoft\\Exchange Server\\V15\\Logging\\CmdletExtensionAgent\\'
      - 'C:\\Program Files\\Microsoft\\Exchange Server\\V15\\Logging\\CmdletProxy\\'
      - 'C:\\Program Files\\Microsoft\\Exchange Server\\V15\\Logging\\CmdletLogging\\'
      - 'C:\\Program Files\\Microsoft\\Exchange Server\\V15\\Logging\\PowerShell\\'
  selection_name:
    TargetFilename|contains:
      - 'Cmdlet'
      - 'CmdletLog'
      - 'CmdletHistory'
      - 'PowerShell'
  condition: selection_path and selection_name
falsepositives:
  - Legitimate administrative maintenance or log rotation processes that remove old cmdlet logs.
  - Backup or cleanup scripts run by Exchange administrators or management tools.
level: high
