# Arquivo: E.yml
title: Creation of doas Configuration File on Linux
id: 1e6b9f3a-4c2d-4f7a-9b8e-2d3c4a5f6b7c
status: experimental
description: Detects creation of the doas configuration file on Linux hosts. Creation of /etc/doas.conf (or equivalent) may indicate an attacker establishing a minimal sudo alternative for persistence or privilege escalation. Requires file creation auditing or file integrity monitoring to capture file create events.
author: Senior Threat Detection Engineer
date: 2026/06/05
references:
  - [https://research.splunk.com/endpoint/linux_doas_conf_file_creation/](https://research.splunk.com/endpoint/linux_doas_conf_file_creation/)
  - [https://www.makeuseof.com/how-to-install-and-use-doas/](https://www.makeuseof.com/how-to-install-and-use-doas/)
tags:
  - attack.persistence
  - attack.privilege_escalation
  - linux
logsource:
  product: linux
  category: file_event
  description: File creation events from auditd, inotify, or file integrity monitoring that include FilePath and Action fields.
detection:
  selection_action:
    Action|in:
      - 'CREATED'
      - 'CREATE'
      - 'created'
      - 'Added'
  selection_path:
    FilePath|endswith:
      - '/etc/doas.conf'
      - '/usr/local/etc/doas.conf'
      - '/etc/doas.d/doas.conf'
  condition: selection_action and selection_path
falsepositives:
  - Legitimate installation or configuration of doas by system administrators or automated configuration management.
  - Packaging or provisioning workflows that create the doas configuration during system build or deployment.
level: high
