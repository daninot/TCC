# Arquivo: A.yml
title: Registry Reconnaissance via reg.exe
id: 0f7a9c3b-2d4e-4b6f-8a1c-9e2f3d4b5a6c
status: experimental
description: Detects use of reg.exe to query sensitive registry locations commonly targeted for credential discovery, persistence, service configuration, shell loading, policies, and logon settings. Matches both the process identity (Image and OriginalFileName) and command-line usage of the query subcommand targeting known sensitive registry keys. Requires process creation logging that captures Image, OriginalFileName, and CommandLine.
author: Senior Threat Detection Engineer
date: 2026/06/11
references:
  - [https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md](https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md)
tags:
  - attack.discovery
  - attack.credential_access
  - attack.persistence
  - windows
logsource:
  product: windows
  category: process_creation
  description: Process creation events (e.g., Sysmon Event ID 1 or equivalent) that include Image, OriginalFileName, and CommandLine fields.
detection:
  selection_process:
    Image|endswith:
      - '\\reg.exe'
      - '\\Reg.exe'
    OriginalFileName|endswith:
      - 'reg.exe'
      - 'Reg.exe'
  selection_query:
    CommandLine|contains:
      - ' query '
      - '/query'
      - ' query\\'
      - ' query"'
  selection_targets:
    CommandLine|contains:
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Run'
      - 'HKCU\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Run'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\RunOnce'
      - 'HKCU\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\RunOnce'
      - 'HKLM\\SYSTEM\\CurrentControlSet\\Services'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Policies'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Explorer\\Shell Folders'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Winlogon'
      - 'HKCU\\SOFTWARE\\Microsoft\\Windows NT\\CurrentVersion\\Winlogon'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Explorer\\ShellExecuteHooks'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Explorer\\Browser Helper Objects'
      - 'HKLM\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Explorer\\AppInit_DLLs'
  condition: all of selection_process selection_query selection_targets
falsepositives:
  - Legitimate administrative or inventory tasks using reg.exe to inspect system configuration.
  - Automated management, monitoring, or deployment tools that query registry keys for health checks or configuration validation.
level: high

# Arquivo: D.yml
title: Registry Reconnaissance via reg.exe Query of Sensitive Keys
id: c3f7a2e1-4b8d-4f1c-b9e4-6a2d5c3f8b17
status: experimental
description: >
  Detects registry query operations performed by reg.exe against sensitive
  registry paths that are commonly targeted during the discovery phase of
  an intrusion. Adversaries enumerate Run and RunOnce keys to identify
  existing persistence mechanisms or to confirm their own implants were
  written correctly; Services keys to map running services and identify
  weak configurations; AppInit_DLLs and Notify keys to find DLL hijacking
  opportunities; Winlogon keys for credential interception targets; and
  security policy keys to understand applied defences. The detection
  combines three mandatory conditions: the executing binary must be reg.exe
  (matched by both image path and OriginalFileName to cover renamed copies),
  the query subcommand must be present, and the command line must reference
  at least one of the sensitive paths. Requiring all three simultaneously
  eliminates noise from unrelated reg.exe usage while maintaining high
  coverage across the documented T1012 procedure examples.
references:
  - https://github.com/redcanaryco/atomic-red-team/blob/f339e7da7d05f6057fdfcdd3742bfcf365fee2a9/atomics/T1012/T1012.md
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.discovery
  - attack.t1012
logsource:
  category: process_creation
  product: windows
detection:
  selection_binary:
    Image|endswith: '\reg.exe'
    OriginalFileName: 'reg.exe'
  selection_subcommand:
    CommandLine|contains: 'query'
  selection_paths:
    CommandLine|contains:
      - '\CurrentVersion\Run'
      - '\CurrentVersion\RunOnce'
      - '\SYSTEM\CurrentControlSet\Services'
      - '\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon'
      - '\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies'
      - '\SOFTWARE\Policies\Microsoft\Windows'
      - '\SYSTEM\CurrentControlSet\Control\Session Manager'
      - '\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows\AppInit_DLLs'
      - '\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Notify'
      - '\SOFTWARE\Microsoft\Windows\CurrentVersion\Authentication\LogonUI'
  condition: selection_binary and selection_subcommand and selection_paths
falsepositives:
  - Endpoint management and configuration compliance tooling such as SCCM,
    Intune remediation scripts, or security baseline scanners that query
    these registry paths as part of automated inventory or compliance
    assessment workflows.
  - Legitimate system administration scripts that enumerate Run keys or
    service configurations during troubleshooting or inventory collection
    procedures.
level: medium
