# Arquivo: A.yml
title: Windows - BazarLoader (KEGTAP/SINGLEMALT) Persistence via Winlogon Registry Hijacking
id: 1e3f9c72-5b84-4d90-a837-6c2e5f1a8d43
status: test
description: |
    Detects modification of the Windows Winlogon Userinit or Shell registry values,
    the primary persistence mechanism documented in FireEye's October 2020 report on
    KEGTAP (BazarLoader) and SINGLEMALT (BazarBackdoor) campaigns by UNC1878
    (WIZARD SPIDER — the threat actor behind TrickBot and Conti ransomware).

    BazarLoader persistence (CISA AA20-302A): the malware appends its binary path
    to the Userinit value, which Windows executes at every interactive logon.
    Standard value: "C:\Windows\system32\userinit.exe,"
    Compromised:    "C:\Windows\system32\userinit.exe,C:\...\malware.exe"
    Any value that is NOT exactly the standard string is a high-confidence IOC.

    The secondary selection covers Winlogon Shell hijacking (replaces explorer.exe),
    a related T1547.004 technique used by malware families in the same ecosystem.

    Threat context:
      Actor: UNC1878 (WIZARD SPIDER)
      Initial access: Phishing linking to Google Docs; EXE payloads named
        Report-Review*.exe, Document_Print.exe, Text_Report.exe
      Co-indicator: %APPDATA%\...\Startup\adobe.lnk (startup folder persistence)
      Post-persistence: Cobalt Strike, BloodHound AD enumeration, Mimikatz
      End-stage: RYUK ransomware — often within 24 hours of initial compromise
      Primary targets: Hospitals, medical centers, retirement communities
references:
    - https://www.fireeye.com/blog/threat-research/2020/10/kegtap-and-singlemalt-with-a-ransomware-chaser.html
    - https://us-cert.cisa.gov/ncas/alerts/aa20-302a
    - https://attack.mitre.org/software/S0534/
    - https://attack.mitre.org/techniques/T1547/004/
    - https://www.lares.com/blog/endpoint-hunting-for-unc1878-kegtap-ttps/
author: Security Team
date: 2026-05-25
tags:
    - attack.persistence
    - attack.t1547.004   # Boot/Logon Autostart: Winlogon Helper DLL
    - attack.defense_evasion
logsource:
    category: registry_set
    product: windows
detection:
    selection_userinit:
        # BazarLoader primary vector: appends malware.exe after the trailing comma
        # Fires on ANY value other than the exact standard string (see filter below)
        TargetObject|endswith: '\CurrentVersion\Winlogon\Userinit'
    selection_shell:
        # Secondary: Winlogon Shell hijacking — replaces explorer.exe with malicious binary
        TargetObject|endswith: '\CurrentVersion\Winlogon\Shell'
    filter_userinit_standard:
        # Exact-match suppression: only the unmodified standard value is whitelisted
        # "C:\Windows\system32\userinit.exe,C:\malware.exe" does NOT match — fires alert
        Details:
            - 'C:\Windows\system32\userinit.exe,'
            - 'C:\WINDOWS\system32\userinit.exe,'
    filter_shell_standard:
        # All accepted standard Windows shell values
        Details:
            - 'explorer.exe'
            - 'C:\Windows\Explorer.exe'
            - 'C:\Windows\explorer.exe'
            - 'C:\WINDOWS\explorer.exe'
    filter_setup_processes:
        # Windows setup and deployment infrastructure legitimately writes these values
        Image|endswith:
            - '\SetupHost.exe'
            - '\TiWorker.exe'
            - '\msiexec.exe'
    condition: ((selection_userinit and not filter_userinit_standard) or
                (selection_shell and not filter_shell_standard))
               and not filter_setup_processes
fields:
    - Image
    - TargetObject
    - Details
    - User
    - ProcessId
falsepositives:
    - Windows OS Feature Updates temporarily modifying Userinit during in-place upgrades
    - Enterprise kiosk or digital signage software overriding the default explorer shell
    - Accessibility or session management tools that replace the default Windows shell
level: high

# Arquivo: C.yml
title: Potential Ryuk Ransomware Deployment via WMIC
id: e4b25e8a-8671-419b-bfdc-4ea8cb59a221
status: experimental
description: Detects the execution of Windows Management Instrumentation Command-line (WMIC) using the '/node' parameter to remotely launch processes. This behavioral pattern was heavily leveraged by the threat group UNC1878 to systematically trigger the final Ryuk ransomware payload binary across multiple targeted systems within compromised enterprise networks.
references:
    - https://cloud.google.com/blog/topics/threat-intelligence/kegtap-and-singlemalt-with-a-ransomware-chaser/
    - https://www.lares.com/blog/endpoint-hunting-for-unc1878-kegtap-ttps/
author: Security Operations Center
date: 2026/05/30
tags:
    - attack.execution
    - attack.lateral_movement
    - attack.t1047 # Windows Management Instrumentation
    - attack.t1486 # Data Encrypted for Impact
logsource:
    product: windows
    category: process_creation
detection:
    selection_wmic:
        Image|endswith: '\wmic.exe'
        CommandLine|contains: '/node:'
    selection_execution:
        CommandLine|contains: 'process call create'
    selection_payload:
        # Looking for paths/indicators associated with the dropped ransomware payloads executed via the WMIC commands
        CommandLine|contains:
            - 'C:\Users\Public\'
            - 'C:\ProgramData\'
            - '\AppData\Local\Temp\'
            - '.exe'
    condition: selection_wmic and selection_execution and selection_payload
falsepositives:
    - Legacy internal network management tools, deployment scripts, or asset tracking applications built by administrators utilizing basic WMIC remoting functions.
level: high

title: Suspicious ANCHOR Style Scheduled Task Creation
id: 6d5c4b6f-7d9e-4e9e-bc3a-2c7f2c3b9d14
status: experimental
description: >
  Detects creation of scheduled tasks matching the ANCHOR persistence
  pattern described in KEGTAP and SINGLEMALT intrusion activity.
  Threat actors associated with ransomware operations were observed
  creating scheduled tasks named "autoupdate#<number>" from randomly
  generated APPDATA directories.
references:
  - https://www.fireeye.com/blog/threat-research/2020/10/kegtap-and-singlemalt-with-a-ransomware-chaser.html
author: OpenAI
date: 2026-05-30
tags:
  - attack.persistence
  - attack.execution
  - attack.t1053.005
logsource:
  product: windows
  category: process_creation
detection:
  selection_img:
    Image|endswith: '\schtasks.exe'
  selection_create:
    CommandLine|contains: '/create'
  selection_task:
    CommandLine|contains|all:
      - 'autoupdate#'
      - '\AppData\'
  condition: all of selection_*
fields:
  - Image
  - CommandLine
  - ParentImage
  - User
  - Computer
falsepositives:
  - Legitimate software using similarly named scheduled tasks
  - Administrative task automation in user profile paths
level: high
