# Arquivo: B.yml
title: DNS Query to Telegram Bot API Indicating Potential C2 Channel Abuse
id: 6d1f4c8b-3e2a-4f7d-b9e1-5c4a2f8d1b37
status: experimental
description: >
  Detects DNS resolution of the Telegram Bot API hostname api.telegram.org,
  which is abused by multiple malware families as a covert command-and-control
  channel. Because Telegram is a widely used legitimate messaging platform,
  its API traffic blends naturally with enterprise outbound traffic and is
  rarely blocked by perimeter controls, making it an attractive covert
  channel for adversaries. TeleRAT is an Android remote access trojan that
  uses the Telegram Bot API to receive commands and exfiltrate data including
  SMS messages and location information from infected devices. TeleCrypt
  ransomware communicated with its operator over the Telegram Bot API to
  exchange encryption keys. KillDisk variants associated with the TeleBots
  group used Telegram bots to receive destructive commands. Beyond these
  documented families, the pattern of abusing Telegram bots for C2 has
  been widely replicated due to the API's simplicity, resilience, and
  TLS encryption. DNS queries to api.telegram.org from workstations,
  servers, or network devices that have no business justification for
  Telegram API access should be treated as an indicator of compromise
  requiring immediate investigation. The exact-match approach avoids
  false positives from unrelated Telegram subdomains while reliably
  catching all bot traffic, which exclusively uses this single hostname.
references:
  - https://core.telegram.org/bots/faq
  - https://researchcenter.paloaltonetworks.com/2018/03/unit42-telerat-another-android-trojan-leveraging-telegrams-bot-api-to-target-iranian-users/
  - https://blog.malwarebytes.com/threat-analysis/2016/11/telecrypt-the-ransomware-abusing-telegram-api-defeated/
  - https://www.welivesecurity.com/2016/12/13/rise-telebots-analyzing-disruptive-killdisk-attacks/
author: Senior Threat Detection Engineer
date: 2026-05-25
tags:
  - attack.command_and_control
  - attack.t1071.001
  - attack.t1102.002
logsource:
  category: dns
detection:
  selection:
    dns.question.name: 'api.telegram.org'
  condition: selection
falsepositives:
  - Endpoints running legitimate Telegram Desktop, Telegram Web, or
    approved third-party applications that interface with the Telegram
    Bot API for sanctioned business purposes such as alerting, notification
    bots, or collaboration integrations. Consider suppressing known
    developer workstations or hosts with documented approval to access
    the Telegram Bot API.
level: medium
