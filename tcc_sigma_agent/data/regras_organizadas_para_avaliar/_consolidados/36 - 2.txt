# Arquivo: E.yml
title: DarkGate Saved or Executed from Temp Directory (AutoIt3 Indicators)
id: 9f8b6c3d-2a4e-4b7f-8c1d-0e2f3a4b5c6d
status: experimental
description: Detects DarkGate loader artifacts saved to or executed from Windows temporary directories where the malware commonly drops AutoIt3 scripts or compiled AutoIt binaries. Matches either a file created in a temp path with AutoIt3-related extensions/names or an executing image launched from a temp path with the same indicators.
author: Senior Threat Detection Engineer
date: 2026/06/09
references:
  - [https://www.bleepingcomputer.com/news/security/hackers-exploit-windows-smartscreen-flaw-to-drop-darkgate-malware/](https://www.bleepingcomputer.com/news/security/hackers-exploit-windows-smartscreen-flaw-to-drop-darkgate-malware/)
  - [https://www.trendmicro.com/en_us/research/24/c/cve-2024-21412--darkgate-operators-exploit-microsoft-windows-sma.html](https://www.trendmicro.com/en_us/research/24/c/cve-2024-21412--darkgate-operators-exploit-microsoft-windows-sma.html)
tags:
  - attack.initial_access
  - attack.persistence
  - malware
  - windows
logsource:
  product: windows
  category: file_event
  description: File creation and process execution events from endpoint telemetry (e.g., Sysmon FileCreate/FileCreateStreamHash and ProcessCreate) that include FilePath/TargetFilePath and Image fields. Ensure file create and process execution events are collected.
detection:
  selection_target:
    TargetFilePath|contains:
      - 'C:\\Temp\\'
      - '\\Temp\\'
      - '\\AppData\\Local\\Temp\\'
    TargetFilePath|endswith:
      - '.au3'
      - '.exe'
      - 'AutoIt3.exe'
      - 'AutoIt3_x64.exe'
      - 'AutoIt3_x86.exe'
      - '.au3x'
  selection_exec:
    Image|contains:
      - 'C:\\Temp\\'
      - '\\Temp\\'
      - '\\AppData\\Local\\Temp\\'
    Image|endswith:
      - '.au3'
      - '.exe'
      - 'AutoIt3.exe'
      - 'AutoIt3_x64.exe'
      - 'AutoIt3_x86.exe'
      - '.au3x'
  condition: 1 of selection_target selection_exec
falsepositives:
  - Legitimate installers, unpackers, or developer tools that run from temporary directories during installation or build processes.
  - Security tooling or automated testing that executes scripts or compiled helpers from temp locations.
level: high
