# Arquivo: A.yml
title: Network - CVE-2023-1389 TP-Link Archer AX21 Unauthenticated Command Injection
id: b8e3f1c7-2a94-4d57-9e06-7c4b8a3d1f29
status: test
description: |
    Detects exploitation attempts targeting CVE-2023-1389, an unauthenticated command
    injection vulnerability in the TP-Link Archer AX21 (AX1800) web management
    interface (firmware prior to 1.1.4 Build 20230219).

    The vulnerable endpoint is the locale API: /cgi-bin/luci/;stok=/locale
    The semicolon in the CGI path (;stok=) is the authentication bypass mechanism.
    Writing to the `country` form concatenates the attacker-supplied value directly
    into a popen() call with no sanitisation, enabling OS command injection as root.

    Two attack vectors covered:
      1. GET (PoC/scanner): payload in URL query string via country=$(CMD)
         Execution requires sending the request TWICE (1st sets, 2nd fires).
      2. POST (Mirai botnet, WAN-side): payload in request body; the botnet
         downloads and executes architecture-specific binaries via wget/busybox.
         Requires a race condition in TP-Link iptables handling for WAN exposure.

    Actively exploited in the wild since April 11, 2023 (ZDI telemetry).
    First observed in Eastern Europe; now global. Campaigns observed by ZDI,
    Fortinet, and others across multiple Mirai variant families.

    NOTE: POST-body detection (Mirai vector) requires a proxy/WAF that logs
    request body content. Standard access logs capture GET payloads only.
references:
    - https://www.tenable.com/security/research/tra-2023-11
    - https://www.zerodayinitiative.com/blog/2023/4/21/tp-link-wan-side-vulnerability-cve-2023-1389-added-to-the-mirai-botnet-arsenal
    - https://github.com/Voyag3r-Security/CVE-2023-1389/blob/4ecada7335b17bf543c0e33b2c9fb6b6215c09ae/archer-rev-shell.py
    - https://www.zerodayinitiative.com/advisories/ZDI-23-451/
    - https://attack.mitre.org/techniques/T1190/
    - https://attack.mitre.org/techniques/T1059/004/
author: Security Team
date: 2026-05-25
tags:
    - attack.initial_access
    - attack.t1190       # Exploit Public-Facing Application
    - attack.execution
    - attack.t1059.004   # Command and Scripting Interpreter: Unix Shell
    - attack.t1105       # Ingress Tool Transfer (Mirai binary download via wget)
    - cve.2023-1389
logsource:
    category: proxy
detection:
    selection_endpoint:
        # The authentication bypass + vulnerable API path — unique to this CVE
        # ;stok= in CGI path bypasses auth; /locale is the injectable API
        cs-uri-stem|contains:
            - '/cgi-bin/luci/;stok='
        cs-uri-stem|contains:
            - 'locale'
    selection_url_injection:
        # GET vector: injection via URL query string (PoC tools, scanners)
        # Covers command substitution syntax and common shell primitives
        cs-uri-query|contains|all:
            - 'country='
            - 'operation=write'
        cs-uri-query|contains:
            - '$('          # command substitution — $(...)
            - ';'           # shell command chaining in country value
            - '`'           # backtick command substitution
    selection_mirai_payload:
        # POST vector: Mirai-specific payload patterns observable in body-logging proxies
        # or in GET requests from opportunistic scanners probing with Mirai payloads
        cs-uri-query|contains:
            - 'wget '       # Mirai binary download from C2
            - 'busybox'     # common IoT shell fallback used by Mirai
            - 'chmod +x'    # make downloaded binary executable
            - '/tmp/'       # staging directory on embedded Linux
            - 'mkfifo'      # reverse shell named pipe creation
            - '/bin/sh'     # explicit shell invocation in payload
    filter_scanners:
        # Suppress known authorized vulnerability scanner CIDRs:
        # c-ip|cidr:
        #     - '10.0.200.0/24'  # internal Nessus/Nexpose scanner
        #     - '203.0.113.0/24' # authorized external pentest
        c-ip: null   # placeholder — populate with authorized scanner IPs
    condition: selection_endpoint and (selection_url_injection or selection_mirai_payload) and not filter_scanners
fields:
    - c-ip
    - cs-method
    - cs-uri-stem
    - cs-uri-query
    - sc-status
    - c-useragent
falsepositives:
    - Authorized internal vulnerability scanners testing for CVE-2023-1389
    - Penetration testers with written authorization targeting TP-Link devices
    - Network security tooling performing periodic IoT firmware CVE checks
level: critical

description: Detects attempts to exploit the unauthenticated command injection in the /cgi-bin/luci/;stok=/locale endpoint (country parameter) of TP‑Link Archer AX21 (CVE-2023-1389). Matches HTTP POSTs with payloads containing shell metacharacters or common PoC strings used to execute commands as root.
author: Security Analyst
date: 2026-05-30
references:
  - https://www.tenable.com/security/research/tra-2023-11
  - https://nvd.nist.gov/vuln/detail/CVE-2023-1389
  - https://packetstormsecurity.com/files/174131/TP-Link-Archer-AX21-Command-Injection.html
logsource:
  product: webserver
  service: httpd
  category: web_access
detection:
  selection_target_path:
    HttpMethod: "POST"
    Uri|contains:
      - "/cgi-bin/luci/;stok=/locale"
      - "/cgi-bin/luci/;stok=/locale?form=country"
  selection_body_indicators:
    RequestBody|contains:
      - "country="
      - "country=$("
      - "country=`"
      - "country=;"

  selection_payload_patterns:
    RequestBody|contains:
      - "$(id>"
      - "id>/tmp"
      - ">/tmp/"
      - "id>"
      - "$(/bin/sh"
      - "||"
      - ";"
      - "`id`"
  condition: selection_target_path and (selection_body_indicators or selection_payload_patterns)
fields:
  - timestamp
  - ClientIP
  - HttpMethod
  - Uri
  - UserAgent
  - RequestBody
  - ResponseStatus
falsepositives:
  - Authorized security scans or penetration tests targeting TP-Link devices
  - Automated management tools that post locale/country values (rarely include shell metacharacters)
level: critical
tags:
  - attack.initial_access
  - attack.t1190

# Arquivo: E.yml
title: TP-Link Archer AX21 Command Injection Attempt (CVE-2023-1389)
id: f092f6b1-098d-4e92-938b-cfb2745cf2a4
status: experimental
description: Detects inbound HTTP POST network requests attempting to exploit a command injection vulnerability (CVE-2023-1389) in the web management interface of TP-Link Archer AX21 routers. Adversaries, such as Mirai botnet operators and security researchers testing reverse shells, target the '/cgi-bin/luci;stok=/locale' endpoint, manipulating the unsanitized 'country' parameter via a 'write' operation to execute arbitrary code as root.
references:
    - https://www.tenable.com/security/research/tra-2023-11
    - https://github.com/Voyag3r-Security/CVE-2023-1389/blob/4ecada7335b17bf543c0e33b2c9fb6b6215c09ae/archer-rev-shell.py
    - https://www.zerodayinitiative.com/blog/2023/4/21/tp-link-wan-side-vulnerability-cve-2023-1389-added-to-the-mirai-botnet-arsenal
author: Security Operations Center
date: 2026/05/30
tags:
    - attack.initial_access
    - attack.execution
    - attack.t1190 # Exploit Public-Facing Application
    - attack.t1203 # Exploitation for Client Execution
logsource:
    category: webserver
detection:
    selection_endpoint:
        # Matches the specific location URI containing the matrix parameter behavior used by OpenWrt/LuCI
        cs-method: 'POST'
        cs-uri-path|contains: '/cgi-bin/luci'
    selection_indicators:
        cs-uri-path|contains:
            - 'stok='
            - '/locale'
    selection_body_payload:
        # Inspects the posted content or raw application logs for the operation parameters
        cs-bytes|contains: # Fallback tracking if specific proxy or WAF inspection logs body fields
            - 'operation=write'
            - 'country='
    selection_command_injection:
        # Looks for shell metacharacters or download commands typical of Mirai/reverse shells inside the request parameters
        cs-bytes|contains:
            - ';sh '
            - ';wget '
            - ';curl '
            - '||wget'
            - '||curl'
            - '`wget'
            - '`curl'
    condition: selection_endpoint and selection_indicators and (selection_body_payload or selection_command_injection)
falsepositives:
    - Legitimate administration behavior modifying regional settings via the router's web user interface (though this typically originates internally rather than from external or unauthenticated contexts).
level: critical
