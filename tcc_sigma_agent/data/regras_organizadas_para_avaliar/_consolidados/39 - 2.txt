# Arquivo: A.yml
title: Python PEP 249 SQL Exception Class Names in Application Logs
id: 3d7d7d8e-8ef1-4c29-9e57-0f02efcf7e17
status: experimental
description: Detects PEP 249 database exception class names appearing in Python application logs, which may indicate SQL injection probing or other database exploitation attempts.
logsource:
product: python
category: application
detection:
selection:
message|re: '(?i)\b(?:InterfaceError|DatabaseError|DataError|OperationalError|IntegrityError|InternalError|ProgrammingError|NotSupportedError)\b'
condition: selection
falsepositives:

* Legitimate database failures and application error handling that log DB-API exception names
  level: medium

# Arquivo: E.yml
title: Python PEP 249 SQL Exception Classes in Application Logs
id: b7d3f2a1-6c4e-4f8b-9a2d-1e3f5b6c7d8e
status: experimental
description: Detects Python application error logs that include PEP 249 (Python Database API) SQL exception class names. These exceptions often surface when user-controlled input triggers database errors and can indicate SQL injection probing or other database-related exploitation attempts. Requires application error logging at LOG_LEVEL ERROR or above and collection of full log messages.
author: Senior Threat Detection Engineer
date: 2026/06/11
references:
  - [https://www.python.org/dev/peps/pep-0249/#exceptions](https://www.python.org/dev/peps/pep-0249/#exceptions)
tags:
  - attack.injection
  - web
  - python
  - detection
logsource:
  product: python
  category: application
  description: Application logs from Python services at LOG_LEVEL ERROR or above. Logs must include timestamp, LogLevel, and Message/StackTrace fields.
detection:
  selection_level:
    LogLevel|in:
      - 'ERROR'
      - 'Error'
      - 'error'
      - 'CRITICAL'
      - 'FATAL'
  selection_exception:
    Message|contains:
      - 'Warning'
      - 'Error'
      - 'InterfaceError'
      - 'DatabaseError'
      - 'DataError'
      - 'OperationalError'
      - 'IntegrityError'
      - 'InternalError'
      - 'ProgrammingError'
      - 'NotSupportedError'
      - 'TransactionManagementError'
      - 'DatabaseError:'
      - 'OperationalError:'
      - 'IntegrityError:'
      - 'ProgrammingError:'
  condition: selection_level and selection_exception
falsepositives:
  - Legitimate application bugs, misconfigurations, or transient database connectivity issues producing PEP 249 exceptions.
  - Expected errors from input validation failures or backend maintenance windows.
level: high
