# Threat to detect
A new "Allow" rule is added to the Windows Firewall exception list by the WMI
provider host process (WmiPrvSE.EXE). Adversaries — including ransomware groups
such as Rhysida — abuse this to open inbound ports for lateral movement, C2, or
data exfiltration, typically by invoking PowerShell cmdlets like
"New-NetFirewallRule" or WMI CIM classes such as "MSFT_NetFirewallRule", which
causes the firewall change to be performed under the WmiPrvSE.EXE context
instead of a user-facing shell.

# Target environment
- Product: Windows
- Log source service: Windows Firewall with Advanced Security audit logs
- The detection must combine THREE conditions simultaneously:
  (a) the firewall event indicates that a rule was ADDED;
  (b) the action of the added rule is "Allow", not "Block";
  (c) the process that modified the firewall is WmiPrvSE.EXE running from its
      legitimate system path.
