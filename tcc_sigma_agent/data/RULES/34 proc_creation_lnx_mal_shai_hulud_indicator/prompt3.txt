Generate a SIGMA rule to detect Shai-Hulud malware execution on Linux — a
supply chain worm targeting the npm ecosystem that exfiltrates secrets and
leaves characteristic identifier strings in process command lines.

Target product: linux; log source category: process_creation.

Detection matches characteristic Shai-Hulud strings in CommandLine using
|contains. Include the emerging-threats tag.

References to include:
- https://www.wiz.io/blog/shai-hulud-2-0-ongoing-supply-chain-attack
- https://www.aikido.dev/blog/shai-hulud-strikes-again-hitting-zapier-ensdomains
- https://semgrep.dev/blog/2025/digging-for-secrets-sha1-hulud-the-second-coming-of-the-npm-worm/


Assim como a Regra 11 (Katz Stealer) e a Regra 32, esta é baseada em threat intelligence recente (novembro de 2025). O agente com web search tem vantagem sobre as LLMs estáticas — pode buscar os IoCs atuais de Shai-Hulud e recuperar as strings exatas, enquanto as LLMs do Estágio 3 dependerão exclusivamente do que está nos links das referências ou no seu próprio treinamento.
